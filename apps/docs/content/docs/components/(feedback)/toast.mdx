## Usage

The `Toast` component is used to display temporary notifications. It is built on top of [Ark UI's Toast](https://ark-ui.com/docs/components/toast) logic.

To use toasts, you first need to create a `toaster` using `createToaster` and then render the `Toaster` component at the root of your application (or near the root).

```tsx
import { createToaster, Toaster, Button } from "@moto-ui/react"

const toaster = createToaster({
  placement: "top-end",
  overlap: true,
  gap: 16,
})

const Demo = () => {
  return (
    <>
      <Button
        onClick={() =>
          toaster.create({
            title: "Success",
            description: "Your changes have been saved.",
            type: "success",
          })
        }
      >
        Show Toast
      </Button>
      <Toaster toaster={toaster} />
    </>
  )
}
```

## Anatomy

The `Toast` component is composed of several parts that can be used for custom implementations:

- `Toast.Group`: The container that manages multiple toasts.
- `Toast.Root`: The root container for an individual toast.
- `Toast.Indicator`: A container for icons or spinners based on the toast type.
- `Toast.Title`: The title of the toast.
- `Toast.Description`: The supporting text for the toast.
- `Toast.Control`: A container for action buttons.
- `Toast.ActionTrigger`: A button that triggers a toast action.
- `Toast.CloseTrigger`: A button that closes the toast.
- `Toast.Context`: Provides access to the toast's state via a render prop.

## Props

**Toaster**

The `Toaster` component is a high-level component that simplifies toast rendering.

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| toaster | `CreateToasterReturn` | - | The toaster instance created by `createToaster`. **Required**. |
| indicator | `ReactNode` | - | Custom element to render as the toast indicator (e.g., an icon). |
| title | `ReactNode` | - | Custom element to render as the default title. |
| description | `ReactNode` | - | Custom element to render as the default description. |
| control | `ReactNode` | - | Custom element to render as the default control area. |
| root | `(toast: Options) => ReactNode` | - | A function that returns a custom toast component for a given toast option. |
| dir | `'ltr' \| 'rtl'` | `'ltr'` | The document's text/writing direction. |
| getRootNode | `() => Node \| ShadowRoot \| Document` | - | A root node to correctly resolve document in custom environments. |
| asChild | `boolean` | `false` | Use the provided child element as the default rendered element. |

**createToaster**

The `createToaster` function accepts several options to configure global toast behavior.

| Option | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| placement | `Placement` | `'bottom'` | The placement of the toast group. |
| duration | `number` | - | The duration in milliseconds before the toast closes. |
| overlap | `boolean` | `false` | Whether toasts should overlap. |
| gap | `number` | `16` | The gap between toasts. |
| hotkey | `string[]` | `['altKey', 'KeyT']` | The hotkey that will move focus to the toast group. |
| max | `number` | `24` | The maximum number of toasts. |
| offsets | `string \| Record<string, string>` | `"1rem"` | The offset from the viewport edge. |
| pauseOnPageIdle | `boolean` | `false` | Whether to pause toast when the user leaves the browser tab. |
| removeDelay | `number` | `200` | The delay in milliseconds before removing the toast from the DOM. |
