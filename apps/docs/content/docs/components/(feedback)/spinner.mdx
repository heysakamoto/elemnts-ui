## Usage

The `Spinner` component provides visual feedback to users that a task is in progress.

```tsx
import { Spinner } from "@elemnts-ui/react"

<Spinner />
```

## Examples

### Sizes
Use the **size** prop to adjust the size of the spinner.

<Example name="spinner:sizes" />

### Custom Icon

You can provide a custom icon or any other content to be animated by the spinner. The `Spinner` component will automatically apply the spinning animation to its direct SVG child.

## API Reference
The `Spinner` component is a styled `ark.span` and accepts all standard HTML `span` props in addition to the following variants:

| Prop | Type | Default |
| --- | --- | --- |
| size | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl' \| '2xl'` | `'md'` | The size of the spinner. |
| colorPalette | `'accent' \| 'neutral' \| 'success' \| 'warning' \| 'destructive'` | `'accent'` | The color palette of the spinner. |
| speed | `'slow' \| 'normal' \| 'fast'` | `'normal'` | The rotation speed of the spinner. |
