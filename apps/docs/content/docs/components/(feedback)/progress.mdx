## Usage

The `Progress` component is used to show the completion status of a task. It can be displayed as a linear bar or a circular indicator.

- `Progress`: The root container for the progress component.
- `Progress.Track`: The container for the progress range (linear).
- `Progress.Range`: The visual indicator of the progress value (linear).
- `Progress.Label`: The label for the progress component.
- `Progress.ValueText`: The text representation of the current value.
- `Progress.View`: Renders its children based on the current progress state.
- `Progress.Context`: Provides access to the progress state via a render prop.
- `Progress.RootProvider`: Advanced component for using a custom progress hook.

```tsx
import { Progress } from "@moto-ui/react"

<Progress defaultValue={40}>
  <Progress.Track>
    <Progress.Range />
  </Progress.Track>
</Progress>
```

## Props

**Root**

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| defaultValue | `number` | `50` | The initial value of the progress bar when rendered. |
| value | `number \| null` | - | The controlled value of the progress bar. Set to `null` for indeterminate state. |
| min | `number` | `0` | The minimum allowed value. |
| max | `number` | `100` | The maximum allowed value. |
| orientation | `'horizontal' \| 'vertical'` | `'horizontal'` | The orientation of the progress bar. |
| formatOptions | `NumberFormatOptions` | `{ style: "percent" }` | Options for formatting the value text. |
| locale | `string` | `'en-US'` | The locale to use for formatting the value. |
| id | `string` | - | The unique identifier of the progress bar. |
| ids | `Partial<{ root: string; track: string; label: string; circle: string }>` | - | The ids of the elements in the progress bar. |
| translations | `IntlTranslations` | - | The localized messages to use. |
| onValueChange | `(details: ValueChangeDetails) => void` | - | Callback fired when the value changes. |
| colorPalette | `'accent' \| 'neutral' \| 'success' \| 'warning' \| 'destructive'` | `'accent'` | The color palette of the progress indicator. |
| size | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | The size of the progress bar. |
| asChild | `boolean` | `false` | Use the provided child element as the default rendered element. |

**Label**

| Prop | Type | Default | Description |

| Prop | Type | Default | Description |

**Range**

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |

**ValueText**

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |

**View**

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| state | `'determinate' \| 'indeterminate' \| 'complete'` | - | The state of the progress to show this view for. **Required**. |
| asChild | `boolean` | `false` | Use the provided child element as the default rendered element. |

**Context**
Provides access to the `Progress` API via a render prop.

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| children | `(api: UseProgressContext) => ReactNode` | - | Render prop to access the component API. |

**RootProvider**
Advanced component for using a custom `useProgress` hook.

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| value | `UseProgressReturn` | - | The value returned from the `useProgress` hook. **Required**. |
| asChild | `boolean` | `false` | Use the provided child element as the default rendered element. |

| :--- | :--- |

| :--- | :--- |
