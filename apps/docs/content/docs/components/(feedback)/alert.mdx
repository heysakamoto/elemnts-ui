### Usage
The `Alert` component is used to communicate a message to the user. It is built on top of the [Collapsible](/docs/components/disclosure/collapsible) component, allowing it to be used for dismissible or togglable messages.

- `Alert`: The root container for the alert.
- `Alert.Media`: A container for icons or images.
- `Alert.Title`: The title of the alert.
- `Alert.Description`: The supporting text for the alert.
- `Alert.Control`: A container for action buttons or other controls.
- `Alert.Trigger`: The interactive control that toggles the alert's visibility.
- `Alert.Indicator`: An optional visual cue that reflects the open/closed state.
- `Alert.Context`: Provides access to the alert's state via a render prop.
- `Alert.RootProvider`: Advanced component for using a custom alert hook.

```tsx
import { Alert, Icon } from "@moto-ui/react"

<Alert>
  <Alert.Media>
    <Icon icon="tabler:info-circle" />
  </Alert.Media>
  <Alert.Title>Information</Alert.Title>
  <Alert.Description>This is an important message.</Alert.Description>
</Alert>
```

### Props

**Root**
The `Alert.Root` component accepts all props from the [Ark UI Collapsible](https://ark-ui.com/docs/components/collapsible) component.

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| defaultOpen | `boolean` | - | The initial open state of the alert. |
| disabled | `boolean` | `false` | Whether the alert is disabled. |
| id | `string` | - | The unique identifier of the alert. |
| ids | `Partial<{ root: string; content: string; trigger: string }>` | - | The ids of the elements in the alert. |
| lazyMount | `boolean` | `false` | Whether to enable lazy mounting. |
| open | `boolean` | - | The controlled open state of the alert. |
| unmountOnExit | `boolean` | `false` | Whether to unmount on exit. |
| colorPalette | `'neutral' \| 'accent' \| 'success' \| 'warning' \| 'destructive'` | `'accent'` | The color palette of the alert. |
| onExitComplete | `VoidFunction` | - | The callback invoked when the exit animation completes. |
| onOpenChange | `(details: OpenChangeDetails) => void` | - | Handler called when the alert is opened or closed. |
| asChild | `boolean` | `false` | Use the provided child element as the default rendered element. |
