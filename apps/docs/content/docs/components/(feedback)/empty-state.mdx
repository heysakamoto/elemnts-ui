## Usage

The `EmptyState` component is used to fill empty areas with contextual information. It helps users understand why content is missing and what they can do about it.

- `EmptyState.Root`: The root container for the empty state.
- `EmptyState.Content`: A flex container that centers the content vertically and horizontally.
- `EmptyState.Indicator`: A container for an icon or visual indicator.
- `EmptyState.Title`: The title of the empty state message.
- `EmptyState.Description`: A supporting description providing additional context.
- `EmptyState.Control`: A container for action buttons or controls.

```tsx
import { EmptyState, Icon } from "@moto-ui/react"

<EmptyState.Root>
  <EmptyState.Content>
    <EmptyState.Indicator>
      <Icon icon="tabler:database" width={32} height={32} />
    </EmptyState.Indicator>
    <EmptyState.Title>No data available</EmptyState.Title>
    <EmptyState.Description>
      There are no records to display at this time.
    </EmptyState.Description>
  </EmptyState.Content>
</EmptyState.Root>
```

## Props

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
