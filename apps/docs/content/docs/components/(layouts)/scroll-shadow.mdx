## Usage
Brief guide to importing and setting up `ScrollShadow` component.

```tsx
import { ScrollShadow } from "@moto-ui/react"
```

```tsx
<ScrollShadow>
  <Text>
    {...content}
  </Text>
</ScrollShadow>
```

## API reference

| Prop | Type | Default |
| --- | --- | --- |
| isEnabled | boolean | true |
| hideScrollbar | boolean | true |
| asChild | boolean | - |
| size | number | 40 |

| Variable | Description |
|----------|-------------|
| --scroll-shadow-end-color | The color of the end shadow. |
| --scroll-shadow-start-color | The color of the start shadow. |
