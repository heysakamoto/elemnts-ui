### Usage
Brief guide to importing and setting up `ScrollShadow` component.

```tsx
import { ScrollShadow } from "@moto-ui/react"
```

```tsx
<ScrollShadow>
  <Text>
    {...content}
  </Text>
</ScrollShadow>
```

### API reference

| Prop | Type | Default | Description |
|------|------|----------|-------------|
| isEnabled | boolean | true | Enables or disables the scroll shadows. |
| hideScrollbar | boolean | true | Hides the scrollbar. |
| asChild | boolean | - | Use the provided child element as the default rendered element, combining their props and behavior. |
| size | number | 40 | The size of the shadow. |

| Variable | Description |
|----------|-------------|
| --scroll-shadow-end-color | The color of the end shadow. |
| --scroll-shadow-start-color | The color of the start shadow. |
