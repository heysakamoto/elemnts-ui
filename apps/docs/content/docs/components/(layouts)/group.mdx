## Usage
Use Group to arrange multiple items together with consistent spacing. Pass your items as children.

```tsx
import { Group } from "@moto-ui/react"

<Group>
	{...items}
</Group>
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| fullWidth | boolean | false | Let the children expand to fill the available space. |
| attached | boolean | false | Visually connect the children. |
| as | React.ElementType | undefined | The underlying element to render. |
| asChild | boolean | undefined | Use the provided child element as the default rendered element, combining their props and behavior. |

| Variable | Description |
|----------|-------------|
| --group-radius | Border radius for the group's outer corners (first and last child when attached). |
