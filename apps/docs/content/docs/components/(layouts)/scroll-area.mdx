## Usage
The `ScrollArea` component is a compound component that provides a way to scroll content with custom-styled scrollbars.

- `ScrollArea.Root`: The root container for the scroll area.
- `ScrollArea.RootProvider`: Provides the scroll area context to its children.
- `ScrollArea.Viewport`: The viewport of the scroll area.
- `ScrollArea.Content`: The content container.
- `ScrollArea.Scrollbar`: The scrollbar container.
- `ScrollArea.Thumb`: The draggable thumb of the scrollbar.
- `ScrollArea.Corner`: The corner element where two scrollbars meet.
- `ScrollArea.Context`: Access the scroll area state and methods.

```tsx
import { ScrollArea } from "@moto-ui/react"

<ScrollArea.Root>
  <ScrollArea.Viewport>
    <ScrollArea.Content>
       {/* Your content here */}
    </ScrollArea.Content>
  </ScrollArea.Viewport>
  <ScrollArea.Scrollbar orientation="vertical">
    <ScrollArea.Thumb />
  </ScrollArea.Scrollbar>
  <ScrollArea.Scrollbar orientation="horizontal">
    <ScrollArea.Thumb />
  </ScrollArea.Scrollbar>
  <ScrollArea.Corner />
</ScrollArea.Root>
```

## Variants
Control when scrollbars are shown using the `variant` prop: `hover` (default) displays them on hover, while `always` keeps them visible at all times.

## Props

**Root**

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| variant | `"hover" \| "always"` | `"hover"` | Controls when scrollbars are shown. |
| size | `"xs" \| "sm" \| "md" \| "lg" \| "xl"` | `"md"` | Adjusts the overall scroll area sizing. |
| asChild | `boolean` | `false` | Use the provided child element as the default rendered element. |
| ids | `Partial<{ root: string, viewport: string, content: string, scrollbar: string, thumb: string }>` | - | The ids of the scroll area elements. |

**RootProvider**

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| value | `UseScrollAreaReturn` | - | **Required**. The value returned from `useScrollArea`. |
| asChild | `boolean` | `false` | Use the provided child element as the default rendered element. |

**Scrollbar**

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| orientation | `"horizontal" \| "vertical"` | - | Sets the orientation of the scrollbar. |
| asChild | `boolean` | `false` | Use the provided child element as the default rendered element. |

**Viewport / Content / Thumb / Corner**
Supports `asChild` and standard HTML attributes.

## CSS Variables

**Root**

| Variable | Description |
| --- | --- |
| --corner-width | The width of the Root. |
| --corner-height | The height of the Root. |
| --thumb-width | The width of the slider thumb. |
| --thumb-height | The height of the slider thumb. |

**Viewport**

| Variable | Description |
| --- | --- |
| --scroll-area-overflow-x-start | The distance from the horizontal start edge in pixels. |
| --scroll-area-overflow-x-end | The distance from the horizontal end edge in pixels. |
| --scroll-area-overflow-y-start | The distance from the vertical start edge in pixels. |
| --scroll-area-overflow-y-end | The distance from the vertical end edge in pixels. |
