## Usage
Use the `Grid` component to create grid layouts.
```tsx
import { Grid, GridItem } from "@elemnts-ui/react"
```
```tsx
<Grid>
  <GridItem />
</Grid>
```


## Column span
Set the `colSpan` prop on GridItem to control how many columns it spans.
