## Usage
The `SeparatorGroup` component provides a consistent layout for separating sections with horizontal or vertical rules. It consists of a flex container with automatically spaced children.

- `SeparatorGroup.Root`: The flex container that holds the separators.
- `SeparatorGroup.Item`: The individual separator element.
- `SeparatorGroup.Caption`: An optional caption displayed alongside the separator group.

```tsx
import { SeparatorGroup } from "@moto-ui/react"

<SeparatorGroup.Root>
  <SeparatorGroup.Item />
</SeparatorGroup.Root>
```


## Caption
Use `SeparatorGroup.Caption` to add a label next to a separator for context.

## Accessibility
- `SeparatorGroup.Root` renders a `div` with `role="separator"`.
- `SeparatorGroup.Caption` is rendered as a `span` and should be used to provide context when the separator's purpose is not purely visual.
- Separators are inherently hidden from assistive technology when used in a purely decorative role.
