## Overview

The `DecorativeBox` is a stylized container primarily used for layout scaffolding or highlighting content with background patterns and colors.

<Example name="decorative-box:basic" />

## Usage

```tsx
import { DecorativeBox } from "@elemnts-ui/react";
```

### Basic

By default, the `DecorativeBox` takes up the full width and height of its parent and has an outline and patterned background.

<Example name="decorative-box:basic" />

### Variants

The `DecorativeBox` comes with two variants: `primary` (default) and `secondary`.

<Example name="decorative-box:variants" />

## API Reference
The `DecorativeBox` supports all standard `div` props as well as Panda CSS system properties.

| Prop      | Type                     | Default   |
| --------- | ------------------------ | --------- |
| `variant` | `"primary" \| "secondary"` | `"primary"` | The visual style of the box.          |
