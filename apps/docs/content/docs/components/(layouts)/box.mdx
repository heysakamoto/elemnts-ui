## Usage
The `Box` component offers a straightforward approach to applying styles effortlessly. It grants access to design tokens and delivers exceptional developer experience when crafting responsive styles.
```tsx
import { Box } from "@moto-ui/react"
```

```tsx
<Box>
  {...content}
</Box>
```


## Shorthand
Use shorthand props such as `bgColor` for `backgroundColor` and `p` for `padding` to write styles more concisely.

<ComponentPreview name="box:shorthand" />

## Pseudo props
Use pseudo props like `_hover` to style an element on hover, `_active` to style it on active, and more.

<ComponentPreview name="box:pseudo-props" />

The `Box` component supports all CSS properties as props, making it easy to style elements.
