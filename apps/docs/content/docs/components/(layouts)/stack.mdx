## Usage
The Stack component is a flex container `display: flex` that arranges its children horizontally or vertically.
```tsx
import { Stack } from "@moto-ui/react"
```
```tsx
<Stack>
  {...content}
</Stack>
```


## Vertical
Set the direction prop to "column" to arrange children in a vertical stack.
