## Usage

The component offers a simple way to maintain a specific aspect ratio for your content.

```tsx
import { AspectRatio } from "@moto-ui/react"
```

```tsx
<AspectRatio ratio={16 / 9}>
  <img src="..." alt="..." />
</AspectRatio>
```

## API Reference
The component accepts all `div` properties and the following custom props:

| Prop | Type | Default |
| --- | --- | --- |
| `ratio` | `number \| string` | `1` |
