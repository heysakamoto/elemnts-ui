## Usage

Used to reveal supplemental information when a user hovers or focuses on a target element.

```tsx
import { HoverCard, Portal } from "@moto-ui/react";

<HoverCard.Root>
  <HoverCard.Trigger />
  <Portal>
    <HoverCard.Positioner>
      <HoverCard.Content />
    </HoverCard.Positioner>
  </Portal>
</HoverCard.Root>;
```

## Delays

Control how long after hover or focus the card opens with `openDelay` and otherwise with `closeDelay` props.
