## Usage
The `HoverCard` component is used to reveal supplemental information when a user hovers or focuses on a target element.

- `HoverCard.Root`: The root container for the hover card.
- `HoverCard.RootProvider`: Provides the hover card context to its children.
- `HoverCard.Trigger`: The target element that triggers the hover card.
- `HoverCard.Positioner`: Manages the absolute positioning of the hover card.
- `HoverCard.Content`: The visual container for the hover card's content.
- `HoverCard.Arrow`: An optional arrow that points to the trigger.
- `HoverCard.ArrowTip`: The tip of the arrow.
- `HoverCard.Context`: Access the hover card state and methods.

```tsx
import { HoverCard, Portal, Card } from "@moto-ui/react"

<HoverCard.Root>
  <HoverCard.Trigger asChild>
    <a href="#">@username</a>
  </HoverCard.Trigger>
  <Portal>
    <HoverCard.Positioner>
      <HoverCard.Content asChild>
        <Surface>
           User profile information...
        </Surface>
      </HoverCard.Content>
    </HoverCard.Positioner>
  </Portal>
</HoverCard.Root>
```

## Delays
Set timing with the `openDelay` and `closeDelay` props: `openDelay` controls how long after hover or focus the card opens, and `closeDelay` controls how long after the pointer leaves the trigger or content it closes.

## Props

**Root**

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| closeDelay | `number` | `300` | The duration from when the mouse leaves the trigger or content until the hover card closes. |
| defaultOpen | `boolean` | - | The initial open state of the hover card when rendered. |
| disabled | `boolean` | `false` | Whether the hover card is disabled. |
| id | `string` | - | The unique identifier of the machine. |
| ids | `Partial<{ trigger: string, content: string, positioner: string, arrow: string }>` | - | The ids of the elements in the hover card. |
| immediate | `boolean` | - | Whether to synchronize the present change immediately. |
| lazyMount | `boolean` | `false` | Whether to enable lazy mounting. |
| open | `boolean` | - | The controlled open state of the hover card. |
| openDelay | `number` | `600` | The duration from when the mouse enters the trigger until the hover card opens. |
| positioning | `PositioningOptions` | - | The positioning options for the hover card. |
| present | `boolean` | - | Whether the node is present (controlled by the user). |
| skipAnimationOnMount | `boolean` | `false` | Whether to allow the initial presence animation. |
| unmountOnExit | `boolean` | `false` | Whether to unmount on exit. |
| onExitComplete | `VoidFunction` | - | Function called when the animation ends in the closed state. |
| onFocusOutside | `(event: FocusOutsideEvent) => void` | - | Function called when the focus is moved outside. |
| onInteractOutside | `(event: InteractOutsideEvent) => void` | - | Function called when an interaction happens outside. |
| onOpenChange | `(details: OpenChangeDetails) => void` | - | Function called when the hover card opens or closes. |
| onPointerDownOutside | `(event: PointerDownOutsideEvent) => void` | - | Function called when the pointer is pressed down outside. |

| Attribute | Description |
