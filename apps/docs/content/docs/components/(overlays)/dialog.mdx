## Usage
Use Dialog to present modal content that requires user focus.

- `Dialog.Root`: The root container for the dialog.
- `Dialog.RootProvider`: Provides the dialog context to its children.
- `Dialog.Trigger`: The button that opens the dialog.
- `Dialog.Backdrop`: The semi-transparent overlay behind the dialog.
- `Dialog.Positioner`: Centers and positions the dialog content on the screen.
- `Dialog.Content`: The container for the dialog's content.
- `Dialog.Title`: The title of the dialog, announced by assistive technologies.
- `Dialog.Description`: A brief description of the dialog's purpose.
- `Dialog.CloseTrigger`: A button that closes the dialog.
- `Dialog.Context`: Access the dialog state and methods via a render prop.

```tsx
import { Button, Surface, Dialog, Portal } from "@moto-ui/react"

<Dialog.Root>
  <Dialog.Trigger asChild>
    <Button>Open</Button>
  </Dialog.Trigger>
  <Portal>
    <Dialog.Backdrop />
    <Dialog.Positioner>
      <Dialog.Content asChild>
        <Surface>
          <Surface.Header>
            <Dialog.Title>Title</Dialog.Title>
          </Surface.Header>
          <Surface.Content>
            <Dialog.Description>Description</Dialog.Description>
          </Surface.Content>
          <Surface.Footer>
            <Dialog.CloseTrigger asChild>
              <Button>Close</Button>
            </Dialog.CloseTrigger>
          </Surface.Footer>
        </Surface>
      </Dialog.Content>
    </Dialog.Positioner>
  </Portal>
</Dialog.Root>
```

## Props

**Root**

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| aria-label | `string` | - | Human readable label for the dialog. |
| closeOnEscape | `boolean` | `true` | Whether to close the dialog when the escape key is pressed. |
| closeOnInteractOutside | `boolean` | `true` | Whether to close the dialog when the outside is clicked. |
| defaultOpen | `boolean` | `false` | The initial open state of the dialog when rendered. |
| finalFocusEl | `() => MaybeElement` | - | Element to receive focus when the dialog is closed. |
| id | `string` | - | The unique identifier of the machine. |
| ids | `Partial<{ trigger: string, positioner: string, backdrop: string, content: string, closeTrigger: string, title: string, description: string }>` | - | The ids of the elements in the dialog. |
| initialFocusEl | `() => MaybeElement` | - | Element to receive focus when the dialog is opened. |
| lazyMount | `boolean` | `false` | Whether to enable lazy mounting. |
| modal | `boolean` | `true` | Whether to prevent pointer interaction outside the element. |
| open | `boolean` | - | The controlled open state of the dialog. |
| preventScroll | `boolean` | `true` | Whether to prevent scrolling behind the dialog when it's opened. |
| restoreFocus | `boolean` | - | Whether to restore focus to the previous element on close. |
| role | `'dialog' \| 'alertdialog'` | `'dialog'` | The dialog's role. |
| trapFocus | `boolean` | `true` | Whether to trap focus inside the dialog when it's opened. |
| unmountOnExit | `boolean` | `false` | Whether to unmount on exit. |
| size | `"xs" \| "sm" \| "md" \| "lg" \| "xl" \| "cover" \| "full"` | `"md"` | The size variant of the dialog. |
| placement | `"top" \| "center" \| "bottom"` | `"center"` | The placement of the dialog. |
| onOpenChange | `(details: OpenChangeDetails) => void` | - | Function to call when the dialog's open state changes. |
| onEscapeKeyDown | `(event: KeyboardEvent) => void` | - | Function called when the escape key is pressed. |
| onFocusOutside | `(event: FocusOutsideEvent) => void` | - | Function called when the focus is moved outside. |
| onInteractOutside | `(event: InteractOutsideEvent) => void` | - | Function called when an interaction happens outside. |
| onPointerDownOutside | `(event: PointerDownOutsideEvent) => void` | - | Function called when the pointer is pressed down outside. |
