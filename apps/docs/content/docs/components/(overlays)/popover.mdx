## Usage
The `Popover` component is used to show contextual information anchored to a trigger element.

- `Popover.Root`: The root container for the popover.
- `Popover.RootProvider`: Provides the popover context to its children.
- `Popover.Trigger`: The element that opens the popover.
- `Popover.Anchor`: An optional element to anchor the popover to (different from the trigger).
- `Popover.Positioner`: Manages the absolute positioning of the popover content.
- `Popover.Content`: The visual container for the popover's content.
- `Popover.Title`: The accessible title for the popover.
- `Popover.Description`: A brief description of the popover's content.
- `Popover.CloseTrigger`: A button that closes the popover.
- `Popover.Arrow`: An optional arrow pointing to the trigger.
- `Popover.ArrowTip`: The tip of the arrow.
- `Popover.Indicator`: A visual indicator for the popover state.
- `Popover.Context`: Access the popover state and methods.

```tsx
import { Popover, Portal, Surface, Button } from "@moto-ui/react"

<Popover.Root>
  <Popover.Trigger asChild>
    <Button>Open Popover</Button>
  </Popover.Trigger>
  <Portal>
    <Popover.Positioner>
      <Popover.Content asChild>
        <Surface w="18rem">
          <Surface.Content>
            <Popover.Title>Title</Popover.Title>
            <Popover.Description>Description</Popover.Description>
            <Popover.CloseTrigger>Close</Popover.CloseTrigger>
          </Surface.Content>
        </Surface>
      </Popover.Content>
    </Popover.Positioner>
  </Portal>
</Popover.Root>
```

## Same width
Enable the `positioning.sameWidth` prop to have the popover content match the trigger’s width.

## Props

**Root**

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| autoFocus | `boolean` | `true` | Whether to automatically set focus on the first focusable content. |
| closeOnEscape | `boolean` | `true` | Whether to close the popover when the escape key is pressed. |
| closeOnInteractOutside | `boolean` | `true` | Whether to close the popover when clicking outside. |
| defaultOpen | `boolean` | - | The initial open state of the popover. |
| id | `string` | - | The unique identifier of the machine. |
| ids | `Partial<{ anchor: string, trigger: string, content: string, title: string, description: string, closeTrigger: string, positioner: string, arrow: string }>` | - | The ids of the elements in the popover. |
| immediate | `boolean` | - | Whether to synchronize the present change immediately. |
| initialFocusEl | `() => HTMLElement \| null` | - | The element to focus on when the popover is opened. |
| lazyMount | `boolean` | `false` | Whether to enable lazy mounting. |
| modal | `boolean` | `false` | Whether the popover should be modal. |
| open | `boolean` | - | The controlled open state of the popover. |
| persistentElements | `(() => Element \| null)[]` | - | Persistent elements that should not trigger dismiss. |
| portalled | `boolean` | `true` | Whether the popover is portalled. |
| positioning | `PositioningOptions` | - | The options used to position the popover. |
| present | `boolean` | - | Whether the node is present (controlled by the user). |
| skipAnimationOnMount | `boolean` | `false` | Whether to allow the initial presence animation. |
| unmountOnExit | `boolean` | `false` | Whether to unmount on exit. |
| onEscapeKeyDown | `(event: KeyboardEvent) => void` | - | Function called when the escape key is pressed. |
| onExitComplete | `VoidFunction` | - | Function called when the animation ends. |
| onFocusOutside | `(event: FocusOutsideEvent) => void` | - | Function called when focus moves outside. |
| onInteractOutside | `(event: InteractOutsideEvent) => void` | - | Function called when an interaction happens outside. |
| onOpenChange | `(details: OpenChangeDetails) => void` | - | Function called when the popover opens or closes. |
| onPointerDownOutside | `(event: PointerDownOutsideEvent) => void` | - | Function called when the pointer is pressed down outside. |
| onRequestDismiss | `(event: LayerDismissEvent) => void` | - | Function called when this layer is closed due to a parent. |
