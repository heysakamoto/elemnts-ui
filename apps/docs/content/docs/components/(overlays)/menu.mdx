## Usage

The `Menu` component is a set of primitives you compose to build an accessible dropdown.

```tsx
import { Menu, Portal, Surface, Item, Icon } from "@elemnts-ui/react";

<Menu.Root>
  <Menu.Trigger asChild>
    <button>Open Menu</button>
  </Menu.Trigger>
  <Portal>
    <Menu.Positioner>
      <Menu.Content asChild>
        <Surface w="12rem">
          <Surface.Content p="4">
            <Menu.Item value="edit" asChild>
              <Item>
                <Icon icon="tabler:edit" />
                <Menu.ItemText>Edit</Menu.ItemText>
              </Item>
            </Menu.Item>
            <Menu.Separator />
            <Menu.Item value="delete" asChild>
              <Item>
                <Icon icon="tabler:trash" />
                <Menu.ItemText>Delete</Menu.ItemText>
              </Item>
            </Menu.Item>
          </Surface.Content>
        </Surface>
      </Menu.Content>
    </Menu.Positioner>
  </Portal>
</Menu.Root>;
```
