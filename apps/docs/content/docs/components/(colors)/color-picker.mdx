## Usage
The `ColorPicker` component is a feature-rich compound component that provides a complete interface for color selection, including color areas, sliders, and swatches.

```tsx
import { ColorPicker, Swatch, Surface, Portal, parseColor } from "@moto-ui/react"

const color = parseColor("#eb5e41");

<ColorPicker defaultValue={color}>
  <ColorPicker.Control>
    <ColorPicker.Trigger>
      <ColorPicker.ValueSwatch asChild>
        <Swatch size="sm" />
      </ColorPicker.ValueSwatch>
    </ColorPicker.Trigger>
  </ColorPicker.Control>
  <Portal>
    <ColorPicker.Positioner>
      <ColorPicker.Content>
        <Surface p="8">
          <ColorPicker.Area>
            <ColorPicker.AreaBackground>
              <ColorPicker.AreaThumb />
            </ColorPicker.AreaBackground>
          </ColorPicker.Area>
          <ColorPicker.ChannelSlider channel="hue">
            <ColorPicker.ChannelSliderTrack>
              <ColorPicker.ChannelSliderThumb />
            </ColorPicker.ChannelSliderTrack>
          </ColorPicker.ChannelSlider>
        </Surface>
      </ColorPicker.Content>
    </ColorPicker.Positioner>
  </Portal>
</ColorPicker>
```

## Props

**Root**

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| defaultValue | `Color` | `#000000` | The initial color value when rendered. |
| value | `Color` | - | The controlled color value of the color picker. |
| onValueChange | `(details: ValueChangeDetails) => void` | - | Handler called when the value changes. |
| onValueChangeEnd | `(details: ValueChangeDetails) => void` | - | Handler called when the user stops dragging. |
| defaultFormat | `ColorFormat` | `'rgba'` | The initial color format when rendered. |
| format | `ColorFormat` | - | The controlled color format to use. |
| onFormatChange | `(details: FormatChangeDetails) => void` | - | Callback fired when the color format changes. |
| open | `boolean` | - | The controlled open state of the color picker. |
| defaultOpen | `boolean` | - | The initial open state of the color picker. |
| onOpenChange | `(details: OpenChangeDetails) => void` | - | Handler called when the user opens or closes. |
| disabled | `boolean` | - | Whether the color picker is disabled. |
| readOnly | `boolean` | - | Whether the color picker is read-only. |
| invalid | `boolean` | - | Whether the color picker is invalid. |
| required | `boolean` | - | Whether the color picker is required. |
| name | `string` | - | The name for the form input. |
| closeOnSelect | `boolean` | `false` | Whether to close when a swatch is selected. |
| positioning | `PositioningOptions` | - | The positioning options for the color picker. |
| lazyMount | `boolean` | `false` | Whether to enable lazy mounting. |
| unmountOnExit | `boolean` | `false` | Whether to unmount on exit. |
| initialFocusEl | `() => HTMLElement` | - | The initial focus element when opened. |
| openAutoFocus | `boolean` | `true` | Whether to auto focus when opened. |
| id | `string` | - | The unique identifier of the machine. |
| ids | `Partial<Ids>` | - | The ids of the elements in the color picker. |
| immediate | `boolean` | - | Whether to synchronize the present change immediately. |
| inline | `boolean` | - | Whether to render the color picker inline. |
| colorPalette | `ColorPalette` | `"gray"` | The color palette of the component |
| asChild | `boolean` | `false` | Use the provided child element as the default rendered element. |
