## Usage
The `DatePicker` component is a complex compound component that provides a full-featured date selection interface.

- `DatePicker`: The root container for the date picker.
- `DatePicker.Label`: The label for the date picker.
- `DatePicker.Control`: The container for the input and trigger elements.
- `DatePicker.Input`: The input field for the date.
- `DatePicker.Trigger`: The button that opens the date picker popover.
- `DatePicker.ClearTrigger`: The button that clears the selected date.
- `DatePicker.Positioner`: Positions the content popover.
- `DatePicker.Content`: The content of the date picker popover.
- `DatePicker.View`: A specific view (day, month, or year).
- `DatePicker.ViewControl`: Container for the view triggers (prev, next, view switch).
- `DatePicker.PrevTrigger`: Trigger to go to the previous page of the current view.
- `DatePicker.NextTrigger`: Trigger to go to the next page of the current view.
- `DatePicker.ViewTrigger`: Trigger to switch between views (e.g., from day to month).
- `DatePicker.RangeText`: Displays the current date range or view context text.
- `DatePicker.Table`: The calendar table for the current view.
- `DatePicker.TableHead`: The header section of the calendar table.
- `DatePicker.TableBody`: The body section of the calendar table.
- `DatePicker.TableHeader`: A header cell in the calendar table.
- `DatePicker.TableRow`: A row in the calendar table.
- `DatePicker.TableCell`: A cell in the calendar table.
- `DatePicker.TableCellTrigger`: The trigger within a cell to select a date/month/year.

```tsx
import { DatePicker, InputGroup, IconButton, Icon, Portal, Button } from "@moto-ui/react"

<DatePicker>
  <DatePicker.Label>Date</DatePicker.Label>
  <DatePicker.Control>
    <InputGroup>
      <DatePicker.Input asChild>
        <InputGroup.Input placeholder="YYYY-MM-DD" />
      </DatePicker.Input>
      <InputGroup.Addon>
        <DatePicker.Trigger asChild>
          <IconButton variant="ghost" size="sm">
            <Icon icon="tabler:calendar" />
          </IconButton>
        </DatePicker.Trigger>
      </InputGroup.Addon>
    </InputGroup>
  </DatePicker.Control>
  <Portal>
    <DatePicker.Positioner>
      <DatePicker.Content>
        <DatePicker.View view="day">
          <DatePicker.Context>
            {(api) => (
              <>
                <DatePicker.ViewControl>
                  <DatePicker.PrevTrigger asChild>
                    <IconButton variant="ghost" size="sm"><Icon icon="tabler:chevron-left" /></IconButton>
                  </DatePicker.PrevTrigger>
                  <DatePicker.ViewTrigger asChild>
                    <Button variant="ghost" size="sm">
                      <DatePicker.RangeText />
                    </Button>
                  </DatePicker.ViewTrigger>
                  <DatePicker.NextTrigger asChild>
                    <IconButton variant="ghost" size="sm"><Icon icon="tabler:chevron-right" /></IconButton>
                  </DatePicker.NextTrigger>
                </DatePicker.ViewControl>
                <DatePicker.Table>
                  <DatePicker.TableHead>
                    <DatePicker.TableRow>
                      {api.weekDays.map((weekDay, id) => (
                        <DatePicker.TableHeader key={id}>{weekDay.short}</DatePicker.TableHeader>
                      ))}
                    </DatePicker.TableRow>
                  </DatePicker.TableHead>
                  <DatePicker.TableBody>
                    {api.weeks.map((week, id) => (
                      <DatePicker.TableRow key={id}>
                        {week.map((day, id) => (
                          <DatePicker.TableCell key={id} value={day}>
                            <DatePicker.TableCellTrigger asChild>
                              <IconButton variant="ghost" size="sm">{day.day}</IconButton>
                            </DatePicker.TableCellTrigger>
                          </DatePicker.TableCell>
                        ))}
                      </DatePicker.TableRow>
                    ))}
                  </DatePicker.TableBody>
                </DatePicker.Table>
              </>
            )}
          </DatePicker.Context>
        </DatePicker.View>
      </DatePicker.Content>
    </DatePicker.Positioner>
  </Portal>
</DatePicker>
```
