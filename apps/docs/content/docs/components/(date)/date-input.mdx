## Usage

The `DateInput` component is a compound component that provides an accessible, segmented interface for entering dates. Each part of the date (month, day, year) is an independently focusable and editable segment.

- `DateInput`: The root container (alias for `DateInput.Root`).
- `DateInput.Root`: The root container for the date input.
- `DateInput.RootProvider`: Provides the date input context to its children.
- `DateInput.Label`: The label associated with the date input.
- `DateInput.Control`: The container that wraps the segment group and hidden input.
- `DateInput.SegmentGroup`: Groups all date segments into a single interactive region.
- `DateInput.Segment`: An individual editable segment (e.g., month, day, year, or a literal separator).
- `DateInput.HiddenInput`: A hidden input for native form integration.
- `DateInput.Context`: Provides access to the date input state and API.

```tsx
import { DateInput } from "@moto-ui/react"

<DateInput>
  <DateInput.Label>Date</DateInput.Label>
  <DateInput.Control>
    <DateInput.SegmentGroup>
      <DateInput.Context>
        {(api) =>
          api.segments.map((segment, idx) => (
            <DateInput.Segment key={idx} segment={segment} />
          ))
        }
      </DateInput.Context>
    </DateInput.SegmentGroup>
    <DateInput.HiddenInput />
  </DateInput.Control>
</DateInput>
```

## Accessibility

The `DateInput` uses the spinbutton ARIA pattern for each editable segment, allowing keyboard navigation and value adjustment:

- `Tab` / `Shift+Tab` — Move focus between segments.
- `Arrow Up` / `Arrow Down` — Increment or decrement the focused segment value.
- `Arrow Left` / `Arrow Right` — Move focus to the previous or next segment.
- Typing a digit — Directly enter a value into the focused segment.
- `Backspace` / `Delete` — Clear the focused segment.
