## Usage
The `FileUpload` component provides a way for users to select files. It supports single or multiple file selection, and can be used with a standard trigger or a dropzone.

- `FileUpload.Root`: The root container for the file upload.
- `FileUpload.Label`: The label for the file upload.
- `FileUpload.Trigger`: The button that opens the file selection dialog.
- `FileUpload.Dropzone`: A region where users can drag and drop files.
- `FileUpload.ItemGroup`: A container for the list of selected files.
- `FileUpload.Item`: Represents a single selected file.
- `FileUpload.ItemName`: Displays the name of the file.
- `FileUpload.ItemSizeText`: Displays the size of the file.
- `FileUpload.ItemDeleteTrigger`: A button to remove a file from the list.
- `FileUpload.ItemPreview`: A container for file previews.
- `FileUpload.ItemPreviewImage`: Displays a preview image for the file.
- `FileUpload.ClearTrigger`: A button to clear all selected files.
- `FileUpload.HiddenInput`: The native hidden file input element.

```tsx
import { FileUpload, Button, Tile, Icon } from "@moto-ui/react"

<FileUpload.Root>
  <FileUpload.Label>Upload File</FileUpload.Label>
  <FileUpload.Trigger asChild>
    <Button variant="secondary" size="sm">Select Files</Button>
  </FileUpload.Trigger>
  <FileUpload.ItemGroup>
    <FileUpload.Context>
      {({ acceptedFiles }) =>
        acceptedFiles.map((file, id) => (
          <FileUpload.Item key={id} file={file} asChild>
            <Tile>
              <FileUpload.ItemName />
              <FileUpload.ItemSizeText />
              <FileUpload.ItemDeleteTrigger asChild>
                <Button variant="tertiary" size="xs">X</Button>
              </FileUpload.ItemDeleteTrigger>
            </Tile>
          </FileUpload.Item>
        ))
      }
    </FileUpload.Context>
  </FileUpload.ItemGroup>
  <FileUpload.HiddenInput />
</FileUpload.Root>
```

## Props

**Root**

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| accept | `Record<string, string[]> \| FileMimeType \| FileMimeType[]` | - | The accepted file types. |
| acceptedFiles | `File[]` | - | The controlled accepted files. |
| allowDrop | `boolean` | `true` | Whether to allow drag and drop in the dropzone element. |
| asChild | `boolean` | `false` | Use the provided child element as the default rendered element. |
| capture | `'user' \| 'environment'` | - | The default camera to use when capturing media. |
| defaultAcceptedFiles | `File[]` | - | The default accepted files when rendered. |
| directory | `boolean` | - | Whether to accept directories, only works in webkit browsers. |
| disabled | `boolean` | `false` | Whether the file input is disabled. |
| ids | `Partial<{ root: string; dropzone: string; hiddenInput: string; trigger: string; label: string; item: (id: string) => string; itemName: (id: string) => string; itemSizeText: (id: string) => string; itemPreview: (id: string) => string; itemDeleteTrigger: (id: string) => string; }>` | - | The ids of the elements. |
| invalid | `boolean` | `false` | Whether the file input is invalid. |
| locale | `string` | `'en-US'` | The current locale. |
| maxFiles | `number` | `1` | The maximum number of files. |
| maxFileSize | `number` | `Infinity` | The maximum file size in bytes. |
| minFileSize | `number` | `0` | The minimum file size in bytes. |
| name | `string` | - | The name of the underlying file input. |
| onFileAccept | `(details: FileAcceptDetails) => void` | - | Function called when the file is accepted. |
| onFileChange | `(details: FileChangeDetails) => void` | - | Function called when the value changes, whether accepted or rejected. |
| onFileReject | `(details: FileRejectDetails) => void` | - | Function called when the file is rejected. |
| preventDocumentDrop | `boolean` | `true` | Whether to prevent the drop event on the document. |
| readOnly | `boolean` | `false` | Whether the file input is read-only. |
| required | `boolean` | `false` | Whether the file input is required. |
| transformFiles | `(files: File[]) => Promise<File[]>` | - | Function to transform the accepted files. |
| translations | `IntlTranslations` | - | The localized messages to use. |
| validate | `(file: File, details: FileValidateDetails) => FileError[] \| null` | - | Function to validate a file. |
