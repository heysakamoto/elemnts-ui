## Usage

The component provides a way for users to select files. It supports single or multiple file selection, and can be used with a standard trigger or a dropzone.

```tsx
import { FileUpload } from "@elemnts-ui/react";

<FileUpload.Root>
  <FileUpload.Label>Upload File</FileUpload.Label>
  <FileUpload.Trigger />
  <FileUpload.ItemGroup>
    <FileUpload.Context>
      {({ acceptedFiles }) =>
        acceptedFiles.map((file, id) => (
          <FileUpload.Item key={id} file={file} />
        ))
      }
    </FileUpload.Context>
  </FileUpload.ItemGroup>
  <FileUpload.HiddenInput />
</FileUpload.Root>;
```

| ------- | --------------------- | -------- |
| value   | `UseFileUploadReturn` | required |
| asChild | `boolean`             | `false`  |

| Prop    | Type      | Default |
| ------- | --------- | ------- |
| asChild | `boolean` | `false` |
