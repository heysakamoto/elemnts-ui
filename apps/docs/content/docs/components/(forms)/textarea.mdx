## Usage
The `Textarea` component is a styled wrapper around the native `textarea` element, providing consistent styling across different states and variants.

```tsx
import { Textarea } from "@moto-ui/react"

<Textarea placeholder="Type your message here..." />
```

## Variants
Use the `variant` prop to change the visual style of the textarea.

<ComponentPreview name="textarea:variants" />

- `primary`: The default variant with a subtle background and border.
- `secondary`: A variant with a different background color.
- `tertiary`: A minimal variant without background or border.

## Sizes
Use the `size` prop to change the size of the textarea.

<ComponentPreview name="textarea:sizes" />


## Disabled State
Use the `disabled` prop to prevent user interaction with the textarea.

<ComponentPreview name="textarea:disabled" />


## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| variant | `primary \| secondary \| tertiary` | `primary` | The visual style of the textarea. |
| size | `xs \| sm \| md \| lg \| xl` | `md` | The size of the textarea. |
| asChild | `boolean` | `false` | Use the provided child element as the default rendered element. |
