### Usage
The `Field` component is used to wrap form elements like `Input`, `Textarea`, or `Select` to provide additional context like labels and status messages.

- `Field.Root`: The root container for the field.
- `Field.Label`: The label for the field.
- `Field.Input`: A styled input element optimized for use within a field.
- `Field.Textarea`: A styled textarea element optimized for use within a field.
- `Field.Select`: A styled select element optimized for use within a field.
- `Field.HelperText`: Descriptive text providing additional guidance.
- `Field.ErrorText`: Message displayed when the field is in an invalid state.

```tsx
import { Field } from "@moto-ui/react"

<Field.Root>
  <Field.Label>Username</Field.Label>
  <Field.Input placeholder="Enter your username" />
  <Field.HelperText>Choose a unique public name.</Field.HelperText>
</Field.Root>
```

### Helper Text
Use `Field.HelperText` to provide additional information or instructions for the user.

<ComponentPreview name="field:helper-text" />

### Invalid
Set the `invalid` prop on `Field.Root` to show the `Field.ErrorText`. This will also update the styling of the input to reflect the error state.

<ComponentPreview name="field:invalid" />

### Disabled
Use the `disabled` prop on `Field.Root` to disable the entire field. This will also apply the disabled styling to all child components, such as the label and input.

<ComponentPreview name="field:disabled" />

### Props

**Root**

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| asChild | `boolean` | `false` | Use the provided child element as the default rendered element. |
| disabled | `boolean` | `false` | Indicates whether the field is disabled. |
| ids | `ElementIds` | - | The ids of the field parts. |
| invalid | `boolean` | `false` | Indicates whether the field is invalid. |
| readOnly | `boolean` | `false` | Indicates whether the field is read-only. |
| required | `boolean` | `false` | Indicates whether the field is required. |

**Label**

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| asChild | `boolean` | `false` | Use the provided child element as the default rendered element. |

**Input**

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| asChild | `boolean` | `false` | Use the provided child element as the default rendered element. |

**Textarea**

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| asChild | `boolean` | `false` | Use the provided child element as the default rendered element. |
| autoresize | `boolean` | `false` | Whether the textarea should autoresize. |

**Select**

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| asChild | `boolean` | `false` | Use the provided child element as the default rendered element. |

**HelperText**

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| asChild | `boolean` | `false` | Use the provided child element as the default rendered element. |

**ErrorText**

| Prop | Type | Default | Description |
| --- | --- | --- | --- |

**RequiredIndicator**

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| asChild | `boolean` | `false` | Use the provided child element as the default rendered element. |

**Provider**

### CSS Variables
This component does not use any custom CSS variables. It relies on standard Panda CSS tokens for styling.
