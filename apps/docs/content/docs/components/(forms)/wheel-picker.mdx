### Usage
The `WheelPicker` component is used to select a single value from a list of options using a wheel-like interaction.

- `WheelPicker.Root`: The root container for the wheel picker.
- `WheelPicker.Control`: The container for the wheel picker options.
- `WheelPicker.Options`: The component that renders the list of options.

```tsx
import { WheelPicker } from "@moto-ui/react"

const options = [
  { label: "Gaming", value: "gaming" },
  { label: "Karate", value: "karate" },
  { label: "Cooking", value: "cooking" },
]

<WheelPicker>
  <WheelPicker.Control>
    <WheelPicker.Options options={options} defaultValue="gaming" />
  </WheelPicker.Control>
</WheelPicker>
```
