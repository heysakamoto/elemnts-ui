### Usage
The `Checkbox` component is used to allow users to select one or more options from a set.

- `Checkbox.Root`: The root container for the checkbox.
- `Checkbox.RootProvider`: Provides the checkbox context to its children.
- `Checkbox.Label`: The label for the checkbox.
- `Checkbox.Control`: The visual control for the checkbox.
- `Checkbox.Indicator`: A visual indicator (usually a check icon) when the checkbox is checked.
- `Checkbox.HiddenInput`: The native hidden input for form integration.
- `Checkbox.Group`: A container for grouping multiple checkboxes.
- `Checkbox.GroupProvider`: Provides the checkbox group context to its children.
- `Checkbox.Context`: Access the checkbox state and methods.

```tsx
import { Checkbox, Icon } from "@moto-ui/react"

<Checkbox.Root>
  <Checkbox.Control>
    <Checkbox.Indicator>
      <Icon icon="tabler:check" />
    </Checkbox.Indicator>
  </Checkbox.Control>
  <Checkbox.Label>Accept terms</Checkbox.Label>
  <Checkbox.HiddenInput />
</Checkbox.Root>
```

### Props

**Root**

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| asChild | `boolean` | `false` | Use the provided child element as the default rendered element. |
| checked | `CheckedState` | - | The controlled checked state of the checkbox. |
| defaultChecked | `CheckedState` | - | The initial checked state of the checkbox. |
| disabled | `boolean` | `false` | Whether the checkbox is disabled. |
| form | `string` | - | The id of the form that the checkbox belongs to. |
| id | `string` | - | The unique identifier of the machine. |
| ids | `Partial<{ root: string, hiddenInput: string, control: string, label: string }>` | - | The ids of the elements in the checkbox. Useful for composition. |
| invalid | `boolean` | `false` | Whether the checkbox is invalid. |
| name | `string` | - | The name of the input field in a checkbox. Useful for form submission. |
| readOnly | `boolean` | `false` | Whether the checkbox is read-only. |
| required | `boolean` | `false` | Whether the checkbox is required. |
| value | `string` | `"on"` | The value of checkbox input. Useful for form submission. |
| onCheckedChange | `(details: CheckedChangeDetails) => void` | - | The callback invoked when the checked state changes. |

**RootProvider**

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| value | `UseCheckboxReturn` | - | **Required**. The value returned from `useCheckbox`. |
| asChild | `boolean` | `false` | Use the provided child element as the default rendered element. |

**Group**

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| defaultValue | `string[]` | - | The initial value of `value` when uncontrolled. |
| disabled | `boolean` | `false` | If `true`, the checkbox group is disabled. |
| invalid | `boolean` | `false` | If `true`, the checkbox group is invalid. |
| maxSelectedValues | `number` | - | The maximum number of selected values. |
| name | `string` | - | The name of the input fields in the checkbox group. |
| readOnly | `boolean` | `false` | If `true`, the checkbox group is read-only. |
| value | `string[]` | - | The controlled value of the checkbox group. |
| onValueChange | `(value: string[]) => void` | - | The callback to call when the value changes. |
| asChild | `boolean` | `false` | Use the provided child element as the default rendered element. |
