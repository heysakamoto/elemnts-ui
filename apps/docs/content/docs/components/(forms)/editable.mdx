## Usage

The `Editable` component is used for inline editing of text. It consists of a preview state that can be toggled into an edit state.

- `Editable.Root`: The root container for the editable.
- `Editable.Area`: The container for the preview and input.
- `Editable.Label`: The label for the editable.
- `Editable.Preview`: The read-only view of the value.
- `Editable.Input`: The input field to edit the value.
- `Editable.Control`: The container for the triggers (edit, submit, cancel).

```tsx
import { Editable } from "@moto-ui/react"

<Editable.Root placeholder="Click to edit" defaultValue="Hello World">
  <Editable.Label>Label</Editable.Label>
  <Editable.Area>
    <Editable.Preview />
    <Editable.Input />
  </Editable.Area>
</Editable.Root>
```

## Custom Controls

You can use `Editable.Control` and `Editable.Context` to render custom triggers based on the editing state.

<ComponentPreview name="editable:custom-controls" />

```tsx
import { Editable, Button, Stack } from "@moto-ui/react"

<Editable.Root defaultValue="Click the edit icon">
  <Editable.Area>
    <Editable.Preview />
    <Editable.Input />
  </Editable.Area>
  <Editable.Control>
    <Editable.Context>
      {(editable) =>
        editable.editing ? (
          <Stack direction="row" gap="8">
            <Editable.SubmitTrigger asChild>
              <Button variant="tertiary" size="xs">Save</Button>
            </Editable.SubmitTrigger>
            <Editable.CancelTrigger asChild>
              <Button variant="tertiary" size="xs">Cancel</Button>
            </Editable.CancelTrigger>
          </Stack>
        ) : (
          <Editable.EditTrigger asChild>
            <Button variant="tertiary" size="xs">Edit</Button>
          </Editable.EditTrigger>
        )
      }
    </Editable.Context>
  </Editable.Control>
</Editable.Root>
```

## Props

**Root**

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| activationMode | `'focus' \| 'dblclick' \| 'click' \| 'none'` | `'focus'` | The activation mode for the preview element. |
| asChild | `boolean` | `false` | Use the provided child element as the default rendered element. |
| autoResize | `boolean` | `false` | Whether the editable should auto-resize to fit the content. |
| defaultEdit | `boolean` | `false` | Whether the editable is in edit mode by default. |
| defaultValue | `string` | - | The initial value of the editable when rendered. |
| disabled | `boolean` | `false` | Whether the editable is disabled. |
| edit | `boolean` | - | Whether the editable is in edit mode. |
| finalFocusEl | `() => HTMLElement \| null` | - | The element to receive focus when the editable is closed. |
| form | `string` | - | The associate form of the underlying input. |
| id | `string` | - | The unique identifier of the machine. |
| ids | `Partial<{ root: string; area: string; label: string; preview: string; input: string; control: string; submitTrigger: string; cancelTrigger: string; editTrigger: string; }>` | - | The ids of the elements in the editable. |
| invalid | `boolean` | `false` | Whether the input's value is invalid. |
| maxLength | `number` | - | The maximum number of characters allowed in the editable. |
| name | `string` | - | The name attribute of the editable component. |
| onEditChange | `(details: EditChangeDetails) => void` | - | Function to call when the edit mode changes. |
| onFocusOutside | `(event: FocusOutsideEvent) => void` | - | Function called when the focus is moved outside the component. |
| onInteractOutside | `(event: InteractOutsideEvent) => void` | - | Function called when an interaction happens outside the component. |
| onPointerDownOutside | `(event: PointerDownOutsideEvent) => void` | - | Function called when the pointer is pressed down outside the component. |
| onValueChange | `(details: ValueChangeDetails) => void` | - | Function to call when the value changes. |
| onValueCommit | `(details: ValueChangeDetails) => void` | - | Function to call when the value is committed. |
| onValueRevert | `(details: ValueChangeDetails) => void` | - | Function to call when the value is reverted. |
| placeholder | `string \| { edit: string; preview: string }` | - | The placeholder text for the editable. |
| readOnly | `boolean` | `false` | Whether the editable is read-only. |
| required | `boolean` | `false` | Whether the editable is required. |
| selectOnFocus | `boolean` | `true` | Whether to select the text in the input when it is focused. |
| submitMode | `'enter' \| 'blur' \| 'none' \| 'both'` | `'both'` | The action that triggers submit in the edit mode. |
| translations | `IntlTranslations` | - | The translations for the editable. |
| value | `string` | - | The controlled value of the editable. |
