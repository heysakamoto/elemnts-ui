## Usage
The `SegmentGroup` component is a compound component used for selecting a single option from a set of options.

- `SegmentGroup.Root`: The root container for the segment group.
- `SegmentGroup.RootProvider`: Provides the segment group context to its children.
- `SegmentGroup.Label`: The label for the segment group.
- `SegmentGroup.Indicator`: A visual indicator that moves to the selected item.
- `SegmentGroup.Item`: Represents a single segment in the group.
- `SegmentGroup.ItemText`: Displays the text label of the segment.
- `SegmentGroup.ItemControl`: The visual control for the segment item.
- `SegmentGroup.ItemHiddenInput`: The native hidden radio input for accessibility and form submission.
- `SegmentGroup.Context`: Access the segment group state and methods.

```tsx
import { SegmentGroup } from "@moto-ui/react"

<SegmentGroup.Root defaultValue="daily">
  <SegmentGroup.Indicator />
  <SegmentGroup.Item value="daily">
    <SegmentGroup.ItemText>Daily</SegmentGroup.ItemText>
    <SegmentGroup.ItemControl />
    <SegmentGroup.ItemHiddenInput />
  </SegmentGroup.Item>
  <SegmentGroup.Item value="weekly">
    <SegmentGroup.ItemText>Weekly</SegmentGroup.ItemText>
    <SegmentGroup.ItemControl />
    <SegmentGroup.ItemHiddenInput />
  </SegmentGroup.Item>
</SegmentGroup.Root>
```

## Props

**Root**

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| asChild | `boolean` | `false` | Use the provided child element as the default rendered element. |
| defaultValue | `string` | - | The initial value of the checked radio when rendered. |
| disabled | `boolean` | `false` | If `true`, the radio group will be disabled. |
| form | `string` | - | The associate form of the underlying input. |
| id | `string` | - | The unique identifier of the machine. |
| ids | `Partial<{ root: string, label: string, indicator: string, item: (value: string) => string, itemLabel: (value: string) => string, itemControl: (value: string) => string, itemHiddenInput: (value: string) => string }>` | - | The ids of the elements in the radio. Useful for composition. |
| invalid | `boolean` | `false` | If `true`, the radio group is marked as invalid. |
| name | `string` | - | The name of the input fields in the radio (Useful for form submission). |
| orientation | `'horizontal' \| 'vertical'` | `'horizontal'` | Orientation of the radio group. |
| readOnly | `boolean` | `false` | Whether the radio group is read-only. |
| required | `boolean` | `false` | If `true`, the radio group is marked as required. |
| value | `string` | - | The controlled value of the radio group. |
| onValueChange | `(details: ValueChangeDetails) => void` | - | Function called once a radio is checked. |
