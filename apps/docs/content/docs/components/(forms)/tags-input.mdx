## Usage

The `TagsInput` component is a compound component used for entering and managing a list of tags.

```tsx
import { TagsInput, Button, Icon } from "@moto-ui/react";

<TagsInput.Root defaultValue={["React", "TypeScript"]}>
  <TagsInput.Label>Frameworks</TagsInput.Label>
  <TagsInput.Control>
    <TagsInput.Context>
      {({ value }) =>
        value.map((item, index) => (
          <TagsInput.Item key={index} index={index} value={item}>
            <TagsInput.ItemPreview>
              <TagsInput.ItemText>{item}</TagsInput.ItemText>
              <TagsInput.ItemDeleteTrigger asChild>
                <Button variant="tertiary" size="xs">
                  <Icon icon="tabler:x" width="12" height="12" />
                </Button>
              </TagsInput.ItemDeleteTrigger>
            </TagsInput.ItemPreview>
            <TagsInput.ItemInput />
          </TagsInput.Item>
        ))
      }
    </TagsInput.Context>
    <TagsInput.Input placeholder="Add tag..." />
  </TagsInput.Control>
</TagsInput.Root>;
```

## Clearable

Use the `TagsInput.ClearTrigger` to allow users to remove all tags at once.

### TagsInputLabel

The label for the tags input.

| Prop    | Type      | Default |
| ------- | --------- | ------- |
| asChild | `boolean` | `false` |

### TagsInputControl

Wraps the tags and input elements.

| Prop    | Type      | Default |
| ------- | --------- | ------- |
| asChild | `boolean` | `false` |

### TagsInputInput

The text input used to add tags.

| Prop    | Type      | Default |
| ------- | --------- | ------- |
| asChild | `boolean` | `false` |

### TagsInputItem

Wraps an individual tag.

| Prop     | Type               | Default  |
| -------- | ------------------ | -------- |
| index    | `string \| number` | required |
| value    | `string`           | required |
| asChild  | `boolean`          | `false`  |
| disabled | `boolean`          | -        |

### TagsInputItemPreview

Displays an individual tag when it is not being edited.

| Prop    | Type      | Default |
| ------- | --------- | ------- |
| asChild | `boolean` | `false` |

### TagsInputItemText

Displays the value of an individual tag.

| Prop    | Type      | Default |
| ------- | --------- | ------- |
| asChild | `boolean` | `false` |

### TagsInputItemDeleteTrigger

Removes an individual tag.

| Prop    | Type      | Default |
| ------- | --------- | ------- |
| asChild | `boolean` | `false` |

### TagsInputClearTrigger

Removes all tags.

| Prop    | Type      | Default |
| ------- | --------- | ------- |
| asChild | `boolean` | `false` |
