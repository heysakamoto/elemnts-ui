## Usage
The `TagsInput` component is a compound component used for entering and managing a list of tags.

- `TagsInput.Root`: The root container for the tags input.
- `TagsInput.RootProvider`: Provides the tags input context to its children.
- `TagsInput.Label`: The label for the tags input.
- `TagsInput.Control`: The container for tags and the input field.
- `TagsInput.Input`: The input field for adding new tags.
- `TagsInput.Item`: Represents a single tag.
- `TagsInput.ItemText`: Displays the text value of the tag.
- `TagsInput.ItemDeleteTrigger`: A button to remove a specific tag.
- `TagsInput.ItemPreview`: A container for tag content (text and delete trigger).
- `TagsInput.ItemInput`: An input for editing an existing tag.
- `TagsInput.ClearTrigger`: A button to clear all tags.
- `TagsInput.HiddenInput`: The native hidden input for form integration.
- `TagsInput.Context`: Access the tags input state and methods.

```tsx
import { TagsInput, Button, Icon } from "@moto-ui/react"

<TagsInput.Root defaultValue={["React", "TypeScript"]}>
  <TagsInput.Label>Frameworks</TagsInput.Label>
  <TagsInput.Control>
    <TagsInput.Context>
      {({ value }) =>
        value.map((item, index) => (
          <TagsInput.Item key={index} index={index} value={item}>
            <TagsInput.ItemPreview>
              <TagsInput.ItemText>{item}</TagsInput.ItemText>
              <TagsInput.ItemDeleteTrigger asChild>
                <Button variant="tertiary" size="xs">
                  <Icon icon="tabler:x" width="12" height="12" />
                </Button>
              </TagsInput.ItemDeleteTrigger>
            </TagsInput.ItemPreview>
            <TagsInput.ItemInput />
          </TagsInput.Item>
        ))
      }
    </TagsInput.Context>
    <TagsInput.Input placeholder="Add tag..." />
  </TagsInput.Control>
</TagsInput.Root>
```

## Clearable
Use the `TagsInput.ClearTrigger` to allow users to remove all tags at once.

## Props

**Root**

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| addOnPaste | `boolean` | `false` | Whether to add a tag when you paste values into the tag input. |
| allowOverflow | `boolean` | `false` | Whether to allow tags to exceed max. In this case, we'll attach `data-invalid` to the root. |
| asChild | `boolean` | `false` | Use the provided child element as the default rendered element. |
| autoFocus | `boolean` | `false` | Whether the input should be auto-focused. |
| blurBehavior | `'clear' \| 'add'` | - | The behavior of the tags input when the input is blurred. |
| defaultInputValue | `string` | - | The initial tag input value when rendered. |
| defaultValue | `string[]` | - | The initial tag value when rendered. |
| delimiter | `string \| RegExp` | `","` | The character that triggers the addition of a new tag or splits tags when pasting. |
| disabled | `boolean` | `false` | Whether the tags input should be disabled. |
| editable | `boolean` | `true` | Whether a tag can be edited after creation. |
| form | `string` | - | The associate form of the underlying input element. |
| id | `string` | - | The unique identifier of the machine. |
| ids | `Partial<{ root: string, input: string, hiddenInput: string, clearBtn: string, label: string, control: string, item: (opts: ItemProps) => string, itemDeleteTrigger: (opts: ItemProps) => string, itemInput: (opts: ItemProps) => string }>` | - | The ids of the elements in the tags input. Useful for composition. |
| inputValue | `string` | - | The controlled tag input's value. |
| invalid | `boolean` | `false` | Whether the tags input is invalid. |
| max | `number` | `Infinity` | The max number of tags. |
| maxLength | `number` | - | The max length of the input. |
| name | `string` | - | The name attribute for the input. Useful for form submissions. |
| readOnly | `boolean` | `false` | Whether the tags input should be read-only. |
| required | `boolean` | `false` | Whether the tags input is required. |
| translations | `IntlTranslations` | - | Specifies the localized strings for accessibility. |
| value | `string[]` | - | The controlled tag value. |
| validate | `(details: ValidateArgs) => boolean` | - | Returns a boolean that determines whether a tag can be added. |
| onFocusOutside | `(event: FocusOutsideEvent) => void` | - | Function called when the focus is moved outside the component. |
| onHighlightChange | `(details: HighlightChangeDetails) => void` | - | Callback fired when a tag is highlighted. |
| onInputValueChange | `(details: InputValueChangeDetails) => void` | - | Callback fired when the input value is updated. |
| onInteractOutside | `(event: InteractOutsideEvent) => void` | - | Function called when an interaction happens outside the component. |
| onPointerDownOutside | `(event: PointerDownOutsideEvent) => void` | - | Function called when the pointer is pressed down outside the component. |
| onValueChange | `(details: ValueChangeDetails) => void` | - | Callback fired when the tag values is updated. |
| onValueInvalid | `(details: ValidityChangeDetails) => void` | - | Callback fired when the max tag count is reached or validation fails. |
