## Usage
The `Slider` component is used to select a single value or a range of values from a predefined range.

- `Slider.Root`: The root container for the slider.
- `Slider.RootProvider`: Provides the slider context to its children.
- `Slider.Label`: The label for the slider.
- `Slider.Control`: The container for the slider track and thumb.
- `Slider.Track`: The track that the thumb slides along.
- `Slider.Range`: The visual range representing the selected value.
- `Slider.Thumb`: The draggable handle for adjusting the value.
- `Slider.ValueText`: Displays the current value as text.
- `Slider.MarkerGroup`: A container for slider markers.
- `Slider.Marker`: Individual markers along the track.
- `Slider.DraggingIndicator`: An indicator that appears while dragging.
- `Slider.HiddenInput`: The native hidden input for form integration.
- `Slider.Context`: Access the slider state and methods.

```tsx
import { Slider } from "@moto-ui/react"

<Slider.Root defaultValue={[30]}>
  <Slider.Label>Volume</Slider.Label>
  <Slider.ValueText />
  <Slider.Control>
    <Slider.Track>
      <Slider.Range />
    </Slider.Track>
    <Slider.Thumb index={0} />
  </Slider.Control>
</Slider.Root>
```

## Range
Use the `defaultValue` or `value` prop with an array of values to enable range selection and render multiple thumbs.

## Props

**Root**

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| aria-label | `string[]` | - | The aria-label of each slider thumb. |
| aria-labelledby | `string[]` | - | The `id` of the elements that label each slider thumb. |
| asChild | `boolean` | `false` | Use the provided child element as the default rendered element. |
| defaultValue | `number[]` | - | The initial value of the slider. |
| disabled | `boolean` | `false` | Whether the slider is disabled. |
| form | `string` | - | The id of the form that the slider belongs to. |
| getAriaValueText | `(details: ValueTextDetails) => string` | - | Function that returns a human readable value for the thumb. |
| id | `string` | - | The unique identifier of the machine. |
| ids | `Partial<{ root: string, thumb: (index: number) => string, hiddenInput: (index: number) => string, control: string, track: string, range: string, label: string, valueText: string, marker: (index: number) => string }>` | - | The ids of the elements in the slider. Useful for composition. |
| invalid | `boolean` | `false` | Whether the slider is invalid. |
| max | `number` | `100` | The maximum value of the slider. |
| min | `number` | `0` | The minimum value of the slider. |
| minStepsBetweenThumbs | `number` | `0` | The minimum permitted steps between multiple thumbs. |
| name | `string` | - | The name associated with each slider thumb (when used in a form). |
| orientation | `'horizontal' \| 'vertical'` | `'horizontal'` | The orientation of the slider. |
| origin | `'center' \| 'start' \| 'end'` | `'start'` | The origin of the slider range. |
| readOnly | `boolean` | `false` | Whether the slider is read-only. |
| step | `number` | `1` | The step value of the slider. |
| thumbAlignment | `'center' \| 'contain'` | `'contain'` | The alignment of the slider thumb relative to the track. |
| thumbCollisionBehavior | `'none' \| 'push' \| 'swap'` | `'none'` | Controls how thumbs behave when they collide. |
| thumbSize | `{ width: number; height: number }` | - | The slider thumbs dimensions. |
| value | `number[]` | - | The controlled value of the slider. |
| onFocusChange | `(details: FocusChangeDetails) => void` | - | Function invoked when the slider's focused index changes. |
| onValueChange | `(details: ValueChangeDetails) => void` | - | Function invoked when the value changes. |
| onValueChangeEnd | `(details: ValueChangeDetails) => void` | - | Function invoked when the slider value change is done. |
