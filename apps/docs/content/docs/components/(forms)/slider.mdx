## Usage
Used to select a single value or a range of values from a predefined range.

```tsx
import { Slider } from "@elemnts-ui/react";

<Slider.Root defaultValue={[30]}>
  <Slider.Label>Volume</Slider.Label>
  <Slider.ValueText />
  <Slider.Control>
    <Slider.Track>
      <Slider.Range />
    </Slider.Track>
    <Slider.Thumb index={0} />
  </Slider.Control>
</Slider.Root>;
```

## Range

Use the `defaultValue` or `value` prop with an array of values to enable range selection and render multiple thumbs.

### SliderRootProvider

Provides a slider API returned by `useSlider` to its descendants.

| Prop    | Type              | Default  |
| ------- | ----------------- | -------- |
| value   | `UseSliderReturn` | required |
| asChild | `boolean`         | `false`  |

### SliderLabel

The label for the slider.

| Prop    | Type      | Default |
| ------- | --------- | ------- |
| asChild | `boolean` | `false` |

### SliderControl

Wraps the slider track and thumbs.

| Prop    | Type      | Default |
| ------- | --------- | ------- |
| asChild | `boolean` | `false` |

### SliderHiddenInput

The hidden input used for form submission.

| Prop    | Type      | Default |
| ------- | --------- | ------- |
| asChild | `boolean` | `false` |

### SliderStepGroup

Groups slider steps.

| Prop    | Type      | Default |
| ------- | --------- | ------- |
| asChild | `boolean` | `false` |

### SliderStep

Represents an individual slider step.

| Prop    | Type      | Default  |
| ------- | --------- | -------- |
| value   | `number`  | required |
| asChild | `boolean` | `false`  |

### SliderMarkerGroup

Groups slider markers.

| Prop    | Type      | Default |
| ------- | --------- | ------- |
| asChild | `boolean` | `false` |

### SliderMarker

Represents an individual slider marker.

| Prop    | Type      | Default  |
| ------- | --------- | -------- |
| value   | `number`  | required |
| asChild | `boolean` | `false`  |

### SliderTrack

The track along which the slider thumbs move.

| Prop    | Type      | Default |
| ------- | --------- | ------- |
| asChild | `boolean` | `false` |

### SliderRange

Displays the selected range of the slider.

| Prop    | Type      | Default |
| ------- | --------- | ------- |
| asChild | `boolean` | `false` |

### SliderThumb

The draggable handle used to change a slider value.

| Prop    | Type      | Default  |
| ------- | --------- | -------- |
| index   | `number`  | required |
| asChild | `boolean` | `false`  |
| name    | `string`  | -        |

### SliderValueText

Displays the formatted value of the slider.

| Prop    | Type      | Default |
| ------- | --------- | ------- |
| asChild | `boolean` | `false` |
