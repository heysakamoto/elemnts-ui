## Usage

Allows users to select a single option from a set of mutually exclusive choices.

```tsx
import { RadioGroup } from "@moto-ui/react";

<RadioGroup.Root defaultValue="react">
  <RadioGroup.Label>Framework</RadioGroup.Label>
  <RadioGroup.Item value="react">
    <RadioGroup.ItemControl />
    <RadioGroup.ItemText>React</RadioGroup.ItemText>
    <RadioGroup.ItemHiddenInput />
  </RadioGroup.Item>
  <RadioGroup.Item value="vue">
    <RadioGroup.ItemControl />
    <RadioGroup.ItemText>Vue</RadioGroup.ItemText>
    <RadioGroup.ItemHiddenInput />
  </RadioGroup.Item>
</RadioGroup.Root>;
```

## API Reference

### RadioGroup

The root container for the radio group.

| Prop          | Type                                                                                                                                                                                                                     | Default |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------- |
| asChild       | `boolean`                                                                                                                                                                                                                | `false` |
| defaultValue  | `string`                                                                                                                                                                                                                 | -       |
| disabled      | `boolean`                                                                                                                                                                                                                | -       |
| form          | `string`                                                                                                                                                                                                                 | -       |
| id            | `string`                                                                                                                                                                                                                 | -       |
| ids           | `Partial<{ root: string; label: string; indicator: string; item: (value: string) => string; itemLabel: (value: string) => string; itemControl: (value: string) => string; itemHiddenInput: (value: string) => string }>` | -       |
| invalid       | `boolean`                                                                                                                                                                                                                | -       |
| name          | `string`                                                                                                                                                                                                                 | -       |
| onValueChange | `(details: ValueChangeDetails) => void`                                                                                                                                                                                  | -       |
| orientation   | `"horizontal" \| "vertical"`                                                                                                                                                                                             | -       |
| readOnly      | `boolean`                                                                                                                                                                                                                | -       |
| required      | `boolean`                                                                                                                                                                                                                | -       |
| value         | `string`                                                                                                                                                                                                                 | -       |

### RadioGroupRootProvider

Provides the radio group context to its children.

| Prop    | Type                  | Default  |
| ------- | --------------------- | -------- |
| value   | `UseRadioGroupReturn` | required |
| asChild | `boolean`             | `false`  |

### RadioGroupLabel

The label for the radio group.

| Prop    | Type      | Default |
| ------- | --------- | ------- |
| asChild | `boolean` | `false` |

### RadioGroupItem

Represents an individual radio item in the group.

| Prop     | Type      | Default  |
| -------- | --------- | -------- |
| value    | `string`  | required |
| asChild  | `boolean` | `false`  |
| disabled | `boolean` | -        |
| invalid  | `boolean` | -        |

### RadioGroupItemText

The text label associated with a radio item.

| Prop    | Type      | Default |
| ------- | --------- | ------- |
| asChild | `boolean` | `false` |

### RadioGroupItemControl

The visual control for a radio item.

| Prop    | Type      | Default |
| ------- | --------- | ------- |
| asChild | `boolean` | `false` |

### RadioGroupItemHiddenInput

The native hidden radio input for accessibility and form submission.

| Prop    | Type      | Default |
| ------- | --------- | ------- |
| asChild | `boolean` | `false` |

### RadioGroupIndicator

A visual indicator that can be used to highlight the selected item.

| Prop    | Type      | Default |
| ------- | --------- | ------- |
| asChild | `boolean` | `false` |
