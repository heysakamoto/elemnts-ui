## Usage
The `RadioGroup` component allows users to select a single option from a set of mutually exclusive choices.

- `RadioGroup.Root`: The root container for the radio group.
- `RadioGroup.RootProvider`: Provides the radio group context to its children.
- `RadioGroup.Label`: The label for the radio group.
- `RadioGroup.Item`: Represents an individual radio item in the group.
- `RadioGroup.ItemText`: The text label associated with a radio item.
- `RadioGroup.ItemControl`: The visual control for the radio item.
- `RadioGroup.ItemHiddenInput`: The native hidden radio input for accessibility and form submission.
- `RadioGroup.Indicator`: A visual indicator that can be used to highlight the selected item.
- `RadioGroup.Context`: Access the radio group state and methods.

```tsx
import { RadioGroup } from "@moto-ui/react"

<RadioGroup.Root defaultValue="react">
  <RadioGroup.Label>Framework</RadioGroup.Label>
  <RadioGroup.Item value="react">
    <RadioGroup.ItemControl />
    <RadioGroup.ItemText>React</RadioGroup.ItemText>
    <RadioGroup.ItemHiddenInput />
  </RadioGroup.Item>
  <RadioGroup.Item value="vue">
    <RadioGroup.ItemControl />
    <RadioGroup.ItemText>Vue</RadioGroup.ItemText>
    <RadioGroup.ItemHiddenInput />
  </RadioGroup.Item>
</RadioGroup.Root>
```

Use the `orientation="horizontal"` prop to display the radio group items horizontally.

## Props

**Root**

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| asChild | `boolean` | `false` | Use the provided child element as the default rendered element. |
| defaultValue | `string` | - | The initial value of the checked radio when rendered. |
| disabled | `boolean` | `false` | If `true`, the radio group will be disabled. |
| form | `string` | - | The associate form of the underlying input. |
| id | `string` | - | The unique identifier of the machine. |
| ids | `Partial<{ root: string, label: string, indicator: string, item: (value: string) => string, itemLabel: (value: string) => string, itemControl: (value: string) => string, itemHiddenInput: (value: string) => string }>` | - | The ids of the elements in the radio. Useful for composition. |
| invalid | `boolean` | `false` | If `true`, the radio group is marked as invalid. |
| name | `string` | - | The name of the input fields in the radio (Useful for form submission). |
| orientation | `'horizontal' \| 'vertical'` | `'vertical'` | Orientation of the radio group. |
| readOnly | `boolean` | `false` | Whether the radio group is read-only. |
| required | `boolean` | `false` | If `true`, the radio group is marked as required. |
| value | `string` | - | The controlled value of the radio group. |
| onValueChange | `(details: ValueChangeDetails) => void` | - | Function called once a radio is checked. |
