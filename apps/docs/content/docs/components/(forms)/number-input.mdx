### Usage
The `NumberInput` component is a compound component that provides a way to enter and adjust numerical values.

- `NumberInput.Root`: The root container for the number input.
- `NumberInput.RootProvider`: Provides the number input context to its children.
- `NumberInput.Label`: The label for the number input.
- `NumberInput.Input`: The input field for the numerical value.
- `NumberInput.Control`: The container for the increment and decrement triggers.
- `NumberInput.IncrementTrigger`: The button to increment the value.
- `NumberInput.DecrementTrigger`: The button to decrement the value.
- `NumberInput.Scrubber`: A region that allows users to change the value by dragging.
- `NumberInput.ValueText`: Displays the formatted value of the number input.
- `NumberInput.Context`: Access the number input state and methods.

```tsx
import { NumberInput, Button, Icon } from "@moto-ui/react"

<NumberInput.Root defaultValue="10">
  <NumberInput.Label>Quantity</NumberInput.Label>
  <NumberInput.Input />
  <NumberInput.Control>
    <NumberInput.DecrementTrigger asChild>
      <Button variant="tertiary" size="xs">
        <Icon icon="tabler:minus" width="14" height="14" />
      </Button>
    </NumberInput.DecrementTrigger>
    <NumberInput.IncrementTrigger asChild>
      <Button variant="tertiary" size="xs">
        <Icon icon="tabler:plus" width="14" height="14" />
      </Button>
    </NumberInput.IncrementTrigger>
  </NumberInput.Control>
</NumberInput.Root>
```

### Props

**Root**

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| allowMouseWheel | `boolean` | `false` | Whether to allow mouse wheel to change the value. |
| allowOverflow | `boolean` | `true` | Whether to allow the value overflow the min/max range. |
| asChild | `boolean` | `false` | Use the provided child element as the default rendered element, combining their props and behavior. |
| clampValueOnBlur | `boolean` | `true` | Whether to clamp the value when the input loses focus (blur). |
| defaultValue | `string` | - | The initial value of the input when rendered. |
| disabled | `boolean` | `false` | Whether the number input is disabled. |
| focusInputOnChange | `boolean` | `true` | Whether to focus input when the value changes. |
| form | `string` | - | The associate form of the input element. |
| formatOptions | `Intl.NumberFormatOptions` | - | The options to pass to the `Intl.NumberFormat` constructor. |
| id | `string` | - | The unique identifier of the machine. |
| ids | `Partial<{ root: string, label: string, input: string, incrementTrigger: string, decrementTrigger: string, scrubber: string }>` | - | The ids of the elements in the number input. Useful for composition. |
| inputMode | `InputMode` | `'decimal'` | Hints at the type of data that might be entered by the user. |
| invalid | `boolean` | `false` | Whether the number input value is invalid. |
| locale | `string` | `'en-US'` | The current locale. Based on the BCP 47 definition. |
| max | `number` | `Number.MAX_SAFE_INTEGER` | The maximum value of the number input. |
| min | `number` | `Number.MIN_SAFE_INTEGER` | The minimum value of the number input. |
| name | `string` | - | The name attribute of the number input. Useful for form submission. |
| pattern | `string` | `"-?[0-9]*(.[0-9]+)?"` | The pattern used to check the input element's value against. |
| readOnly | `boolean` | `false` | Whether the number input is readonly. |
| required | `boolean` | `false` | Whether the number input is required. |
| spinOnPress | `boolean` | `true` | Whether to spin the value when the increment/decrement button is pressed. |
| step | `number` | `1` | The amount to increment or decrement the value by. |
| translations | `IntlTranslations` | - | Specifies the localized strings that identifies the accessibility elements and their states. |
| value | `string` | - | The controlled value of the input. |
| onFocusChange | `(details: FocusChangeDetails) => void` | - | Function invoked when the number input is focused. |
| onValueChange | `(details: ValueChangeDetails) => void` | - | Function invoked when the value changes. |
| onValueCommit | `(details: ValueChangeDetails) => void` | - | Function invoked when the value is committed (when the input is blurred or the Enter key is pressed). |
| onValueInvalid | `(details: ValueInvalidDetails) => void` | - | Function invoked when the value overflows or underflows the min/max range. |
