## Usage
The `PasswordInput` component is a compound component that provides a secure way to enter passwords, with built-in support for toggling visibility.

- `PasswordInput.Root`: The root container for the password input.
- `PasswordInput.RootProvider`: Provides the password input context to its children.
- `PasswordInput.Label`: The label for the password input.
- `PasswordInput.Control`: The container for the input and visibility trigger.
- `PasswordInput.Input`: The input field for the password.
- `PasswordInput.VisibilityTrigger`: The button that toggles the password visibility.
- `PasswordInput.Indicator`: Displays different content based on the visibility state.
- `PasswordInput.Context`: Access the password input state and methods.

```tsx
import { PasswordInput, InputGroup, Button, Icon } from "@moto-ui/react"

<PasswordInput.Root>
  <PasswordInput.Control>
    <InputGroup>
      <PasswordInput.Input asChild>
        <InputGroup.Input placeholder="Enter your password" />
      </PasswordInput.Input>
      <InputGroup.Addon>
        <PasswordInput.VisibilityTrigger asChild>
          <Button variant="ghost" size="sm">
            <PasswordInput.Indicator
              fallback={<Icon icon="tabler:eye-off" />}
            >
              <Icon icon="tabler:eye" />
            </PasswordInput.Indicator>
          </Button>
        </PasswordInput.VisibilityTrigger>
      </InputGroup.Addon>
    </InputGroup>
  </PasswordInput.Control>
</PasswordInput.Root>
```

## Props

**Root**

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| autoComplete | `'current-password' \| 'new-password'` | `'current-password'` | The autocomplete attribute for the password input. |
| defaultVisible | `boolean` | `false` | The initial visibility of the password input. |
| disabled | `boolean` | `false` | Whether the password input is disabled. |
| id | `string` | - | The unique identifier of the machine. |
| ids | `Partial<{ input: string; visibilityTrigger: string }>` | - | The ids of the password input parts. |
| ignorePasswordManagers | `boolean` | `false` | When `true`, the input will ignore password managers. |
| invalid | `boolean` | `false` | The invalid state of the password input. |
| name | `string` | - | The name of the password input. |
| readOnly | `boolean` | `false` | Whether the password input is read only. |
| required | `boolean` | `false` | Whether the password input is required. |
| translations | `Partial<{ visibilityTrigger: (visible: boolean) => string }>` | - | Localized messages for the visibility trigger. |
| visible | `boolean` | - | The controlled visibility of the password input. |
| onVisibilityChange | `(details: VisibilityChangeDetails) => void` | - | Function called when the visibility changes. |
| asChild | `boolean` | `false` | Use the provided child element as the default rendered element. |
