## Usage

The `Tag` component is used to label, categorize, or organize items using keywords that describe them.

```tsx
import { Tag } from "@moto-ui/react"

<Tag>Tag Content</Tag>
```

## Props

The `Tag` component is a styled `ark.div` and accepts all standard HTML `div` props in addition to the following:

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| size | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | The size of the tag. |
| tone | `'primary' \| 'secondary' \| 'tertiary'` | `'primary'` | The visual tone of the tag. |
| variant | `'primary' \| 'secondary' \| 'tertiary'` | `'primary'` | The variant style when the tag is active. |
| iconOnly | `boolean` | `false` | Whether the tag contains only an icon. |
| selected | `boolean` | `false` | Whether the tag is in an selected state. |
| disabled | `boolean` | `false` | Whether the tag is disabled. |

## Data Attributes

| Attribute | Description |
| :--- | :--- |
| `[data-selected]` | Present when the tag is active. |
| `[data-disabled]` | Present when the tag is disabled. |
