## Usage

Provides a clean way to iterate over an array and render its items. It also supports a fallback UI when the array is empty.

```tsx
import { For } from "@moto-ui/react"

<For each={items} fallback={<p>No items found.</p>}>
  {(item, index) => <div key={index}>{item}</div>}
</For>
```

## API Reference
| Prop | Type | Default |
| --- | --- | --- |
| each | `T[] \| readonly T[]` | `undefined` | - |
| fallback | `ReactNode` | - |
| children | `(item: T, index: number) => ReactNode` | - |
