## Usage

The `For` component provides a clean way to iterate over an array and render its items. It also supports a fallback UI when the array is empty.

```tsx
import { For } from "@moto-ui/react"

<For each={items} fallback={<p>No items found.</p>}>
  {(item, index) => <div key={index}>{item}</div>}
</For>
```

## Props

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| each | `T[] \| readonly T[]` | `undefined` | - | The array of items to iterate over. |
| fallback | `ReactNode` | - | Optional content to render when the array is empty. |
| children | `(item: T, index: number) => ReactNode` | - | A render function called for each item in the array. |
