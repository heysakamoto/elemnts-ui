## Usage

A visual indicator that represents a selected or unselected state in a circular format. It is primarily used within radio button components or any selection interface that requires a circular marker.

```tsx
import { Radiomark } from "@moto-ui/react"

<Radiomark checked />
```

## API Reference
Accepts all standard HTML **span** props in addition to the following:

| Prop | Type | Default |
| --- | --- | --- |
| checked | `boolean` | `false` |
| disabled | `boolean` | `false` |
| size | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | The size of the radiomark. |
