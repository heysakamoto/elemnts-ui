## Usage

A utility provider that establishes a substrate level context for all its children. This level (a value clamped between 1 and 8) is typically consumed by components like **Elevated** or **Surface** to dynamically adjust background colors, borders, and shadows based on depth.

```tsx
import { Substrate } from "@moto-ui/react"

<Substrate value={3}>
	<YourComponent />
</Substrate>
```

## Context Hook

You can access the current substrate level in custom components using the **useSubstrate** hook. This is useful when you need to write custom components whose layouts or rendering logic depend on how deeply nested they are within other layers.

```tsx
import { useSubstrate } from "@moto-ui/react"

function MyComponent() {
	const level = useSubstrate();
	return <div>Current Level: {level}</div>;
}
```
