## Usage

Used to manage the mounting and unmounting of components with animations. It tracks the animation and transition states of its children to ensure they are fully animated out before being hidden or unmounted.

```tsx
import { Presence } from "@moto-ui/react"

<Presence present={present}>
  <div>Content to animate</div>
</Presence>
```

## Examples

### Unmount on Exit

Use the **unmountOnExit** prop to completely remove the component from the DOM when it's not present.

## API Reference

| Prop | Type | Default |
| --- | --- | --- |
| present | `boolean` | `false` |
| lazyMount | `boolean` | `false` |
| unmountOnExit | `boolean` | `false` |
| onExitComplete | `() => void` | - |
