## Usage

The `Presence` component is used to manage the mounting and unmounting of components with animations. It tracks the animation and transition states of its children to ensure they are fully animated out before being hidden or unmounted.

```tsx
import { Presence } from "@moto-ui/react"

<Presence present={present}>
  <div>Content to animate</div>
</Presence>
```

## Props

The `Presence` component accepts all props from the [Ark UI Presence](https://ark-ui.com/docs/utilities/presence) component.

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| present | `boolean` | `false` | Whether the component should be present (visible). |
| lazyMount | `boolean` | `false` | Whether to defer rendering until the first time `present` is true. |
| unmountOnExit | `boolean` | `false` | Whether to unmount the component when `present` is false. |
| onExitComplete | `() => void` | - | Function called when the exit animation is complete. |

## Data Attributes

| Attribute | Description |
| :--- | :--- |
| `[data-state]` | The current state: `open` or `closed`. |
| `[data-present]` | Present when the component is visible or animating. |
