## Usage

Wraps your content and applies the appropriate color scheme based on the **appearance** prop. It sets the **data-color-scheme** attribute and CSS **color-scheme** property on the wrapper element.

```tsx
import { Theme, Text } from "@moto-ui/react"

<Theme appearance="dark">
  <Text>This content is wrapped in a dark color scheme.</Text>
</Theme>
```
