### Usage

The `Portal` component is used to transport its children to a different part of the DOM tree, typically at the end of the `document.body`. This is particularly useful for UI elements like modals, tooltips, and popovers that need to break out of their parent's overflow and stacking context.

```tsx
import { Portal } from "@moto-ui/react"

<Portal>
  <div>I am rendered at the end of document.body</div>
</Portal>
```

### Examples

#### Custom Container

By default, the `Portal` renders into `document.body`. You can specify a custom container by passing a ref to the `container` prop.

<ComponentPreview name="portal:custom-container" />

#### Disabled

You can disable the portal by passing `disabled={true}`. When disabled, the children will be rendered at the location where the `Portal` component is defined.

<ComponentPreview name="portal:disabled" />


### Props

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| container | `RefObject<HTMLElement>` | `document.body` | The container element to render the portal into. |
| disabled | `boolean` | `false` | Whether the portal is disabled. |


The `Portal` component does not have any specific data attributes as it is a utility component that doesn't render an extra wrapping element in the target container (it only renders its children).
