## Usage

The Tile component is used to present information or options in a structured, visually distinct container. It supports compound components for flexible layout.

```tsx
import { Tile } from "@elemnts-ui/react";

<Tile>
  <Tile.Content>
    <Tile.Title>Settings</Tile.Title>
    <Tile.Description>...</Tile.Description>
  </Tile.Content>
</Tile>;
```

## API Reference

### Root

| Prop | Type | Default |
| ------ | ------ | ----- |
| variant | `"primary" \| "secondary" \| "tertiary"` | `"primary"`| 
| size | `"xs" \| "sm" \| "md" \| "lg" \| "xl"` | `"md"` |
| orientation  | `"horizontal" \| "vertical"` | `"horizontal"` |
| selected     | `boolean` | `false` |
