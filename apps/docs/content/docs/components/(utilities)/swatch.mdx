## Usage

The `Swatch` component is a simple circular indicator used to display a color. It is commonly used within color pickers, palette generators, or to document design tokens.

```tsx
import { Swatch } from "@moto-ui/react"

<Swatch bg="red.500" />
```

## Examples

### Sizes

The `Swatch` component supports multiple sizes: `xs`, `sm`, `md` (default), `lg`, and `xl`.

<ComponentPreview name="swatch:sizes" />

## Props

The `Swatch` component is a styled `ark.div` and accepts all standard HTML `div` props, including Panda CSS style props (like `bg`, `borderColor`, etc.), in addition to the following:

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| size | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | The size of the swatch. |
| asChild | `'boolean' \| 'undefined'` | Use the provided child element as the default rendered element, combining their props and behavior. |
