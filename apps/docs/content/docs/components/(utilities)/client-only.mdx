## Usage

The `ClientOnly` component wraps content that should only be rendered on the client after hydration. During server-side rendering the optional `fallback` is shown instead, preventing hydration mismatches caused by browser-only APIs or non-deterministic values.

```tsx
import { ClientOnly } from "@moto-ui/react"

<ClientOnly>
  <p>I only render on the client.</p>
</ClientOnly>
```

## Props

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| children | `ReactNode \| (() => ReactNode)` | - | Content to render on the client. Can be a render function for deferred evaluation. |
| fallback | `ReactNode` | `undefined` | Content rendered during SSR and before hydration. |

## Accessibility

`ClientOnly` does not produce any DOM element of its own. It returns only its children or fallback, so semantic structure and ARIA attributes are determined entirely by the content you pass in.
