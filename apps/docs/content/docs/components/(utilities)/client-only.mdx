## Usage

Wraps content that should only be rendered on the client after hydration. During server-side rendering the optional **fallback** is shown instead, preventing hydration mismatches caused by browser-only APIs or non-deterministic values.

```tsx
import { ClientOnly } from "@moto-ui/react"

<ClientOnly>
  <p>I only render on the client.</p>
</ClientOnly>
```

## API Reference
| Prop | Type | Default |
| --- | --- | --- |
| children | `ReactNode \| (() => ReactNode)` | - | Content to render on the client. Can be a render function for deferred evaluation. |
| fallback | `ReactNode` | `undefined` |
