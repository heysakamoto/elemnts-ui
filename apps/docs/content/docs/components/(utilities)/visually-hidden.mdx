## Usage

Renders content that is visually hidden but remains available to assistive technologies like screen readers. This is useful for providing accessible labels to icons, enhancing context for screen reader users, or hiding decorative content.

```tsx
import { VisuallyHidden } from "@elemnts-ui/react"

<button type="button">
  <Icon>
    <BellIcon />
  </Icon>
  <VisuallyHidden>Notifications</VisuallyHidden>
</button>
```
