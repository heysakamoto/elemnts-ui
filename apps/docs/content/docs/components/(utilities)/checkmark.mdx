## Usage

The `Checkmark` component is a visual indicator that represents a checked, unchecked, or indeterminate state. It is commonly used as part of checkboxes, radio buttons, or selection lists.

```tsx
import { Checkmark, Icon } from "@moto-ui/react"

<Checkmark checked>
  <Icon icon="tabler:check" />
</Checkmark>
```

## Props

The `Checkmark` component is a styled `ark.div` and accepts all standard HTML `div` props in addition to the following:

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| checked | `boolean` | `false` | Whether the checkmark is in a checked state. |
| indeterminate | `boolean` | `false` | Whether the checkmark is in an indeterminate state. |
| disabled | `boolean` | `false` | Whether the checkmark is disabled. |
| fallback | `ReactNode` | - | The element to render when `indeterminate` is true. |
| size | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | The size of the checkmark. |
| colorPalette | `'accent' \| 'neutral' \| 'success' \| 'warning' \| 'destructive'` | `'accent'` | The color palette of the checkmark. |
| variant | `'primary' \| 'secondary'` | `'primary'` | The visual style of the checkmark. |

## Data Attributes

| Attribute | Description |
| :--- | :--- |
| `[data-state]` | The current state: `checked`, `indeterminate`, or `unchecked`. |
| `[data-checked]` | Present when the checkmark is checked. |
| `[data-indeterminate]` | Present when the checkmark is indeterminate or checked. |
| `[data-disabled]` | Present when the checkmark is disabled. |
