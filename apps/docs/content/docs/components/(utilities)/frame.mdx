### Usage
The `Frame` component renders its children inside an isolated `<iframe>`, providing complete style and DOM isolation from the parent page. This is useful for embedded widgets, preview panes, sandboxed content, or any scenario where CSS encapsulation is needed.

```tsx
import { Frame } from "@moto-ui/react"
```

```tsx
<Frame>
  {...content}
</Frame>
```

The component automatically handles portal rendering into the iframe document, environment context, and resizing to match content dimensions.

### Head prop
Inject styles, scripts, or meta tags into the iframe's `<head>` using the `head` prop.

<ComponentPreview name="frame:head" />


### Props

| Prop | Type | Description |
|---|---|---|
| `head` | `ReactNode` | Content to render inside the iframe's `<head>` element |
| `onMount` | `fn()` | Callback invoked when the iframe document mounts |
| `onUnmount` | `fn()` | Callback invoked when the iframe document unmounts |
| `srcDoc` | `string` | Custom HTML document for the iframe (has sensible default) |
