## Usage
Renders its children inside an isolated **iframe**, providing complete style and DOM isolation from the parent page. This is useful for embedded widgets, preview panes, sandboxed content, or any scenario where CSS encapsulation is needed.

```tsx
import { Frame } from "@moto-ui/react"
```

```tsx
<Frame>
  {...content}
</Frame>
```

## Head prop
Inject styles, scripts, or meta tags into the iframe's `<head>` using the `head` prop.
