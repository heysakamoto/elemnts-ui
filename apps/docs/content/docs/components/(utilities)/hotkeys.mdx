## API Reference

### createHotkeyStore

| Prop                | Type                                        | Default Value |
| :------------------ | :------------------------------------------ | :------------ |
| `activeScopes`      | `string \| string[]`                        | `['*']`       |
| `conflictBehavior`  | `'warn' \| 'error' \| 'replace' \| 'allow'` | `'warn'`      |
| `defaultOptions`    | `HotkeyOptions`                             | `undefined`   |
| `sequenceTimeoutMs` | `number`                                    | `1000`        |
| `returns`           | `HotkeyStore`                               | `undefined`   |

### useHotkey

| Prop    | Type             | Default Value |
| :------ | :--------------- | :------------ |
| `props` | `UseHotkeyProps` | `undefined`   |

### useHotkeys

| Prop       | Type                  | Default Value |
| :--------- | :-------------------- | :------------ |
| `commands` | `UseHotkeysCommand[]` | `undefined`   |
| `store`    | `HotkeyStore`         | `undefined`   |
| `id`       | `string`              | `undefined`   |

### UseHotkeysCommand

| Prop          | Type                             | Default Value |
| :------------ | :------------------------------- | :------------ |
| `id`          | `string`                         | `undefined`   |
| `hotkey`      | `string`                         | `undefined`   |
| `action`      | `(event: KeyboardEvent) => void` | `undefined`   |
| `label`       | `string`                         | `undefined`   |
| `description` | `string`                         | `undefined`   |
| `category`    | `string`                         | `undefined`   |
