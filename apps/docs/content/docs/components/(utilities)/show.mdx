## Usage

Provides a declarative way to conditionally render content. When the **when** prop is truthy, the children are rendered. When falsy, the optional **fallback** is shown instead.

```tsx
import { Show } from "@elemnts-ui/react"

<Show when={isLoggedIn} fallback={<p>Please log in.</p>}>
  <p>Welcome back!</p>
</Show>
```

## API Reference
| Prop | Type | Default |
| --- | --- | --- |
| when | `T \| null \| undefined` | - | The value to check for truthiness. When truthy, children are rendered. |
| fallback | `ReactNode` | - |
| children | `ReactNode \| ((props: T) => ReactNode)` | - | The content to render when `when` is truthy. Can be a render function that receives the truthy value. |
