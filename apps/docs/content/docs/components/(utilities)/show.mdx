### Usage

The `Show` component provides a declarative way to conditionally render content. When the `when` prop is truthy, the children are rendered. When falsy, the optional `fallback` is shown instead.

```tsx
import { Show } from "@moto-ui/react"

<Show when={isLoggedIn} fallback={<p>Please log in.</p>}>
  <p>Welcome back!</p>
</Show>
```

### Props

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| when | `T \| null \| undefined` | - | The value to check for truthiness. When truthy, children are rendered. |
| fallback | `ReactNode` | - | Optional content to render when `when` is falsy. |
| children | `ReactNode \| ((props: T) => ReactNode)` | - | The content to render when `when` is truthy. Can be a render function that receives the truthy value. |

### Accessibility

The `Show` component does not produce any DOM elements of its own. It only returns its children or fallback, so no ARIA attributes or keyboard interaction are required. Semantic structure is preserved by the content passed as children.
