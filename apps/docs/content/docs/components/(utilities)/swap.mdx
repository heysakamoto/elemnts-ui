## Usage
A flexible utility for switching between two different states or indicators, such as a play/pause button, sun/moon for theme toggling, or a checkmark/copy icon.

```tsx
import { Swap, Icon, Button } from "@moto-ui/react"
import { useState } from "react"

export const Demo = () => {
  const [swapped, setSwapped] = useState(false)

  return (
    <Button iconOnly onClick={() => setSwapped(!swapped)}>
      <Swap swap={swapped}>
        <Swap.Indicator type="on">
          <Icon icon="tabler:sun" />
        </Swap.Indicator>
      </Swap>
    </Button>
  )
}
```

## API Reference

### SwapRoot
The root container for the swap component.

| Prop | Type | Default |
| --- | --- | --- |
| mode | `'flip' \| 'scale' \| 'rotate' \| 'fade'` | - |
| swap | `boolean` | `false` |


### SwapIndicator
Represents one of the two states (on or off).

| Prop | Type | Default |
| --- | --- | --- |
| type | `'on' \| 'off'` | - | **Required**. Specifies which state this indicator represents. |
| asChild | `boolean` | `false` |
