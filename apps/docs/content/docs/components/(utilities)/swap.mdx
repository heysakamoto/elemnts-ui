## Usage
The `Swap` component is a flexible utility for switching between two different states or indicators, such as a play/pause button, sun/moon for theme toggling, or a checkmark/copy icon.

- `Swap.Root`: The root container for the swap component.
- `Swap.RootProvider`: Provides the swap context to its children.
- `Swap.Indicator`: Represents one of the two states (on or off).

```tsx
import { Swap, Icon, Button } from "@moto-ui/react"
import { useState } from "react"

export const Demo = () => {
  const [swapped, setSwapped] = useState(false)
  
  return (
    <Button iconOnly onClick={() => setSwapped(!swapped)}>
      <Swap.Root swap={swapped}>
        <Swap.Indicator type="on">
          <Icon icon="tabler:sun" />
        </Swap.Indicator>
        <Swap.Indicator type="off">
          <Icon icon="tabler:moon" />
        </Swap.Indicator>
      </Swap.Root>
    </Button>
  )
}
```

## Props

**Root**

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| swap | `boolean` | `false` | Whether the swap is in the "on" state. |
| mode | `'fade' \| 'rotate' \| 'scale' \| 'flip'` | `'fade'` | The animation mode to use when swapping. |
| lazyMount | `boolean` | `false` | Whether to enable lazy mounting. |
| unmountOnExit | `boolean` | `false` | Whether to unmount on exit. |
| asChild | `boolean` | `false` | Use the provided child element as the default rendered element. |

**RootProvider**

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| value | `UseSwapReturn` | - | **Required**. The value returned from `useSwap`. |
| asChild | `boolean` | `false` | Use the provided child element as the default rendered element. |

**Indicator**

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| type | `'on' \| 'off'` | - | **Required**. Specifies which state this indicator represents. |
| asChild | `boolean` | `false` | Use the provided child element as the default rendered element. |

## Data Attributes

**Root**

| Attribute | Description |
| :--- | :--- |
| `data-scope` | `swap` |
| `data-part` | `root` |
| `data-state` | The current state: `open` (on) or `closed` (off). |

**Indicator**

| Attribute | Description |
| :--- | :--- |
| `data-scope` | `swap` |
| `data-part` | `indicator` |
| `data-state` | The current state: `open` (on) or `closed` (off). |
