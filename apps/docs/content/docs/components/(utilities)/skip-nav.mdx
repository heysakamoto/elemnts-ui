## Usage

The `SkipNav` component provides a skip navigation link that is visually hidden until focused via keyboard navigation. When activated, it moves focus to the main content area, allowing users to bypass repetitive navigation elements.

```tsx
import { SkipNav } from "@moto-ui/react"

<SkipNav.Root>
	<SkipNav.Link>Skip to main content</SkipNav.Link>
	<SkipNav.Content>
		{/* Main content */}
	</SkipNav.Content>
</SkipNav.Root>
```

## Anatomy

The `SkipNav` component consists of three parts:

| Part | Description |
| :--- | :--- |
| `Root` | The wrapper component that provides the styling context. |
| `Link` | The skip link rendered as an anchor element. Hidden until focused via keyboard navigation. |
| `Content` | The target container that receives focus when the skip link is activated. |

## Custom ID

Both `Link` and `Content` accept an `id` prop to customize the target identifier. By default, they use `"moto-skip-nav"`. When providing a custom `id`, both components must use the same value for the link to correctly target the content.

```tsx
<SkipNav.Root>
	<SkipNav.Link id="my-skip-nav">Skip to main content</SkipNav.Link>
	<SkipNav.Content id="my-skip-nav">
		{/* Main content */}
	</SkipNav.Content>
</SkipNav.Root>
```

## Props

### SkipNavRoot

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| children | `ReactNode` | - | The content to render within the root wrapper. |
| as | `ArkComponent` | `div` | The underlying HTML element or component. |

### SkipNavLink

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| id | `string` | `"moto-skip-nav"` | The ID of the target content element. |
| children | `ReactNode` | - | The link text. |
| as | `ArkComponent` | `a` | The underlying HTML element or component. |

### SkipNavContent

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| id | `string` | `"moto-skip-nav"` | The ID that the skip link targets. |
| children | `ReactNode` | - | The content to render within the target container. |
| as | `ArkComponent` | `div` | The underlying HTML element or component. |

## Accessibility

The `SkipNav` component follows [WCAG 2.1 Technique](https://www.w3.org/WAI/WCAG21/Techniques/general/G1).

- The link is visually hidden using a well-established screen reader only technique until it receives keyboard focus
- When focused, the link becomes fully visible and positioned at the top of the page
- Activating the link moves focus to the content area, bypassing navigation landmarks
- The content area receives `tabIndex={-1}` to ensure it can receive programmatic focus without disrupting the natural tab order
