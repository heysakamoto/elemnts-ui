## Usage

Provides a skip navigation link that is visually hidden until focused via keyboard navigation. When activated, it moves focus to the main content area, allowing users to bypass repetitive navigation elements.

```tsx
import { SkipNav } from "@moto-ui/react"

<SkipNav.Root>
	<SkipNav.Link>Skip to main content</SkipNav.Link>
	<SkipNav.Content>
		{/* Main content */}
	</SkipNav.Content>
</SkipNav.Root>
```
