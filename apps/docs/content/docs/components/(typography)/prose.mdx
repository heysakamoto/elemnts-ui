## Overview

Add typographic styles to raw HTML or markdown content. It helps design beautiful, readable document layouts without manual styling of individual elements.

<Example name="prose:basic" />

## Usage

Use the component to render rich text content with automatic typography and spacing styles. It targets standard nested HTML tags like **h1**, **h2**, **p**, **blockquote**, and **lists**.

```tsx
import { Prose } from "@moto-ui/react"
```

```tsx
<Prose>
	<h1>Heading</h1>
	<p>This is a paragraph inside the prose container.</p>
</Prose>
```
