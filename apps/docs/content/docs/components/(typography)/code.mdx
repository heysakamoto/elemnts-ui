## Usage

Used to display inline code or short code snippets. It styles the default HTML `<code>` element using design tokens to ensure consistent typography and background highlights.

```tsx
import { Code } from "@elemnts-ui/react";
```

```tsx
<Code>npm install @elemnts-ui/react</Code>
```

## Sizes

Use the `size` prop to change the font size and padding of the code block.

## API Reference

| Prop | Type | Default |
| -------- | ------------- | ----------- |
| size      | `xs` \| `sm` \| `md` \| `lg` \| `xl` | `md`         |
| variant   | `primary` \| `secondary` \| `tertiary` \| `surface` \| `ghost` | `primary`   |
| iconOnly | `boolean` | `false` |
| asChild  | `boolean` | `undefined` |
