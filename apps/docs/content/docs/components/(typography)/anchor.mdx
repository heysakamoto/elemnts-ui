## Usage

The component simplifies styling with design tokens and an ergonomic API for responsive designs.

```tsx
import { Anchor } from "@elemnts-ui/react";
```

```tsx
<Anchor>{...content}</Anchor>
```

## API Reference

| Prop         | Type                | Default     |
| ------------ | ------------------- | ----------- | 
| variant      | `primary` \| `secondary` \| `tertiary` | `primary`   | 
| asChild      | `boolean` | `undefined` |
