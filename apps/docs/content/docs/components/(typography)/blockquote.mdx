## Usage

A compound component that provides a semantic way to display quotations. Use it to display a quotation with optional attribution.

```tsx
import { Blockquote } from "@moto-ui/react";
```

```tsx
<Blockquote>
  <BlockquoteContent>
    <p>The best way to predict the future is to invent it.</p>
  </BlockquoteContent>
  <BlockquoteCaption>— Alan Kay, Computer Scientist</BlockquoteCaption>
</Blockquote>
```

## API Reference

### BlockquoteRoot

The root component for the Blockquote.
| Prop | Type | Default |
| --- | --- | --- |
| as | `React.ElementType` | `figure`
| asChild | `boolean` | `false`

### BlockquoteContent
The content of the Blockquote.
| Prop | Type | Default |
| --- | --- | --- |
| as | `React.ElementType` | `blockquote`
| asChild | `boolean` | `false`

### BlockquoteCaption
The caption of the Blockquote.
| Prop | Type | Default |
| --- | --- | --- |
| as | `React.ElementType` | `figcaption`
| asChild | `boolean` | `false`
