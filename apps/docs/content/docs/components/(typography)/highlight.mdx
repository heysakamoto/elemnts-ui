## Usage
Use the `Highlight` component to emphasize substrings in text that match the provided query.
```tsx
import { Text, Highlight } from "@moto-ui/react"
```

```tsx
<Text>
  <Highlight
    query="..."
    text="..."
  />
</Text>
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| variant | `primary \| secondary \| tertiary \| underline` | `primary` | Specifies the components visual style variant |
| palette | `accent \| neutral \| warning \| success \| destructive` | `accent` | Specifies the color palette used to render the highlight |
| query | `string \| string[]` | `undefined` | The query to highlight in the text |
| text | `string` | `undefined` | The text to highlight |
| ignoreCase | `boolean` | `undefined` | Whether to ignore case while matching |
| matchAll | `boolean` | `undefined` | Whether to match multiple instances of the query |
| exactMatch | `boolean` | `undefined` | Whether to match whole words only |
