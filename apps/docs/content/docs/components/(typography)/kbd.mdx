## Usage
The Kbd component displays keyboard keys and shortcuts for an action. Use Kbd.Item to represent individual keys or key combinations.
```tsx
import { Kbd } from "@elemnts-ui/react"
```

```tsx
<Kbd>
  <Kbd.Item />
</Kbd>
```

## API Reference

### KbdGroup
Groups multiple kbd component together

| Prop | Type | Default |
| --- | --- | --- |
| variant | `'primary' \| 'secondary' \| 'tertiary' \| 'surface' \| 'ghost'` | `primary` |
| as | `React.ElementType` | `undefined` |
| asChild | `boolean` | `undefined` |

### KbdGroupSeparator
Separates kbd within a group

| Prop | Type | Default |
| --- | --- | --- |
| variant | `'primary' \| 'secondary' \| 'tertiary' \| 'surface' \| 'ghost'` | `primary` |
| as | `React.ElementType` | `undefined` |
| asChild | `boolean` | `undefined` |

### Kbd

| Prop | Type | Default |
| --- | --- | --- |
