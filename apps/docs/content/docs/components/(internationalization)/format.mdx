---
title: Format
description: A set of components used to format numbers, bytes, and relative time according to the current locale.
---

### Number

The `Format.Number` component formats a number based on the current locale and specified options. It uses the `Intl.NumberFormat` API internally.

<ComponentPreview name="format:number" />

#### Usage

```tsx
import { Format } from "@moto-ui/react"

<Format.Number
  value={1234.56}
  style="currency"
  currency="USD"
/>
```

### Byte

The `Format.Byte` component formats a byte value into a human-readable string (e.g., KB, MB, GB).

<ComponentPreview name="format:byte" />

#### Usage

```tsx
import { Format } from "@moto-ui/react"

<Format.Byte value={1024} />
```

### Relative Time

The `Format.RelativeTime` component formats a date into a relative time string (e.g., "2 days ago", "in 5 minutes"). It uses the `Intl.RelativeTimeFormat` API internally.

<ComponentPreview name="format:relative-time" />

#### Usage

```tsx
import { Format } from "@moto-ui/react"

<Format.RelativeTime value={new Date()} />
```

### Props

**Format.Number**

Accepts all props from the [Ark UI Format.Number](https://ark-ui.com/docs/components/format) component, which includes all `Intl.NumberFormatOptions`.

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| value | `number` | - | **Required.** The number to format. |

**Format.Byte**

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| value | `number` | - | **Required.** The byte size to format. |
| unit | `'bit' \| 'byte'` | `'byte'` | The unit granularity to display. |
| unitDisplay | `'short' \| 'long' \| 'narrow'` | `'short'` | The unit display style. |
| unitSystem | `'decimal' \| 'binary'` | `'decimal'` | The unit system to use for formatting. |

**Format.RelativeTime**

Accepts all props from the [Ark UI Format.RelativeTime](https://ark-ui.com/docs/components/format) component, which includes all `Intl.RelativeTimeFormatOptions`.

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| value | `Date` | - | **Required.** The date to format. |
