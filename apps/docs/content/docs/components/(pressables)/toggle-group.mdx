## Usage

The `ToggleGroup` component allows users to select one or more options from a set of toggles.

```tsx
import { ToggleGroup } from "@moto-ui/react"
```

```tsx
<ToggleGroup.Root>
	<ToggleGroup.Item value="a">A</ToggleGroup.Item>
	<ToggleGroup.Item value="b">B</ToggleGroup.Item>
</ToggleGroup.Root>
```

## Anatomy

The `ToggleGroup` component consists of the following subcomponents:

- `ToggleGroup.Root`: The root container for the toggle group.
- `ToggleGroup.Item`: A toggle item within the group.
- `ToggleGroup.Context`: A component that provides access to the group's state via a render prop.

## Props

**Root**

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| defaultValue | `string[]` | | The initial selected value of the toggle group. |
| value | `string[]` | | The controlled selected value of the toggle group. |
| onValueChange | `(details: ValueChangeDetails) => void` | | Function to call when the selection changes. |
| multiple | `boolean` | `false` | Whether to allow multiple toggles to be selected. |
| deselectable | `boolean` | `true` | Whether the toggle group allows empty selection. |
| disabled | `boolean` | `false` | Whether the toggle group is disabled. |
| orientation | `"horizontal" \| "vertical"` | `"horizontal"` | The orientation of the toggle group. |
| loopFocus | `boolean` | `true` | Whether to loop focus inside the toggle group. |
| rovingFocus | `boolean` | `true` | Whether to use roving tab index to manage focus. |
| asChild | `boolean` | `false` | Use the provided child element as the default rendered element. |
| attached | `boolean` | `false` | Use the attached variant to visually connect the toggle items together. |
| fullWidth | `boolean` | `false` | Whether the toggle group should take up the full width of its container. |

**Item**

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| value | `string` | | The unique value of the toggle item. **Required**. |
| disabled | `boolean` | `false` | Whether the item is disabled. |
| asChild | `boolean` | `false` | Use the provided child element as the default rendered element. |
