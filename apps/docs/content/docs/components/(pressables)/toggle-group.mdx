## Usage

The `ToggleGroup` component allows users to select one or more options from a set of toggles.

```tsx
import { ToggleGroup } from "@moto-ui/react"
```

```tsx
<ToggleGroup.Root>
	<ToggleGroup.Item value="a">A</ToggleGroup.Item>
	<ToggleGroup.Item value="b">B</ToggleGroup.Item>
</ToggleGroup.Root>
```

## API Reference

### ToggleGroup
Manages the state of the toggle group and provides context for the toggle items.

| Prop | Type | Default |
| --- | --- | --- |
| value | `string` | | - |
| disabled | `boolean` | `false` |
| asChild | `boolean` | `false` |
| multiple | `boolean` | `false` |
| onValueChange | `(value: string) => void` | | 

### ToggleGroupItem
The toggle group item component.

| Prop | Type | Default |
| --- | --- | --- |
| value | `string` | | The unique value of the toggle item. **Required**. |
| disabled | `boolean` | `false` |
| asChild | `boolean` | `false` |
