### Sizes
Set the `size` on the group to scale all contained buttons consistently.

<ComponentPreview name="button-group:sizes" />

### Variants
Use the `variant` prop to set the visual style for all buttons in the group.

<ComponentPreview name="button-group:variants" />

### Palettes
Use the `colorPalette` prop to apply a consistent color scheme to all buttons in the group.

<ComponentPreview name="button-group:palettes" />

### Orientation
Use the `orientation` prop to arrange buttons horizontally or vertically within the group.

<ComponentPreview name="button-group:orientation" />

### Full width
Use the `fullWidth` prop to make buttons expand to fill the available space, distributing width evenly across the group.

<ComponentPreview name="button-group:full-width" />


| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| colorPalette | `accent \| neutral \| warning \| success \| destructive` | `accent` | The color palette of the buttons |
| variant | `secondary \| tertiary \| surface \| ghost \| plain` | `primary` | The variant of the buttons |
| iconOnly | `boolean` | `false` | Renders the buttons as icon-only |
| attached | `boolean` | `false` | Removes spacing between adjacent buttons and merges borders so they appear as a single connected group. |
| fullWidth | `boolean` | `false` | Expands the buttons to the full width of its container |
| orientation | `horizontal \| vertical` | `horizontal` | Arranges buttons horizontally or vertically within the group. |
| as | `React.ElementType` | `undefined` | The underlying element to render. |
| asChild | `boolean` | `undefined` | Use the provided child element as the default rendered element, combining their props and behavior. |
