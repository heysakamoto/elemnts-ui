## Usage
Use the Pagination components together to build page navigation:

- `Pagination`: The root container that manages the pagination state.
- `Pagination.PrevTrigger` / `Pagination.NextTrigger`: Triggers to move to the previous or next page.
- `Pagination.FirstTrigger` / `Pagination.LastTrigger`: Triggers to move to the first or last page.
- `Pagination.Item`: Renders an individual page trigger.
- `Pagination.Ellipsis`: Renders a placeholder for truncated pages.
- `Pagination.Context`: Provides access to the pagination state via a render prop.
- `Pagination.RootProvider`: Advanced component for using a custom pagination hook.

```tsx
import { Pagination, Button, Text } from "@moto-ui/react"

<Pagination count={100} pageSize={10}>
  <Pagination.PrevTrigger asChild>
    <Button variant="ghost">Prev</Button>
  </Pagination.PrevTrigger>
  <Pagination.Context>
    {(api) =>
      api.pages.map((page, index) =>
        page.type === 'page' ? (
          <Pagination.Item key={index} {...page} asChild>
            <Button variant={api.page === page.value ? 'solid' : 'ghost'}>
              {page.value}
            </Button>
          </Pagination.Item>
        ) : (
          <Pagination.Ellipsis key={index} index={index}>
            <Text>...</Text>
          </Pagination.Ellipsis>
        ),
      )
    }
  </Pagination.Context>
  <Pagination.NextTrigger asChild>
    <Button variant="ghost">Next</Button>
  </Pagination.NextTrigger>
</Pagination>
```

## Props

**Root**

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| count | `number` | - | Total number of data items. |
| page | `number` | - | The controlled active page. |
| defaultPage | `number` | `1` | The initial active page when rendered. |
| pageSize | `number` | - | The controlled number of data items per page. |
| defaultPageSize | `number` | `10` | The initial number of data items per page when rendered. |
| siblingCount | `number` | `1` | Number of pages to show beside active page. |
| boundaryCount | `number` | `1` | Number of pages to show at the beginning and end. |
| type | `'button' \| 'link'` | `"button"` | The type of the trigger element. |
| getPageUrl | `(details: PageUrlDetails) => string` | - | Function to generate href attributes for pagination links. |
| ids | `Partial<{ root: string; ellipsis: (index: number) => string; firstTrigger: string; prevTrigger: string; nextTrigger: string; lastTrigger: string; item: (page: number) => string; }>` | - | The ids of the elements in the pagination. |
| onPageChange | `(details: PageChangeDetails) => void` | - | Called when the page number is changed. |
| onPageSizeChange | `(details: PageSizeChangeDetails) => void` | - | Called when the page size is changed. |
| translations | `IntlTranslations` | - | Localized strings for accessibility. |
| asChild | `boolean` | `false` | Use the provided child element as the default rendered element. |

**Item**

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| type | `'page'` | - | The type of the item. **Required**. |
| value | `number` | - | The page number. **Required**. |
| asChild | `boolean` | `false` | Use the provided child element as the default rendered element. |

**Context**
Provides access to the `Pagination` API via a render prop.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| children | `(api: UsePaginationContext) => ReactNode` | - | Render prop to access the component API. |

**RootProvider**
Advanced component for using a custom `usePagination` hook.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| value | `UsePaginationReturn` | - | The value returned from the `usePagination` hook. **Required**. |
| asChild | `boolean` | `false` | Use the provided child element as the default rendered element. |
