## Usage
The Tile component is used to present information or options in a structured, visually distinct container. It supports compound components for flexible layout.

```tsx
import { Icon, Tile } from "@moto-ui/react";

<Tile>
  <Tile.Content>
    <Icon icon="tabler:settings" />
    <Tile.Title>Settings</Tile.Title>
  </Tile.Content>
</Tile>
```

## Props

**Root**

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| tone | `"primary" \| "secondary" \| "tertiary"` | `"primary"` | The visual appearance of the tile |
| variant | `"primary" \| "secondary" \| "tertiary"` | `"primary"` | The variant of the tile |
| size | `"xs" \| "sm" \| "md" \| "lg" \| "xl"` | `"sm"` | The size of the tile |
| orientation | `"horizontal" \| "vertical"` | `"horizontal"` | The orientation of the content |
| colorPalette | `"accent" \| "success" \| "warning" \| "neutral" \| "destructive"` | `"accent"` | The color palette of the tile |
| selected | `boolean` | `false` | Whether the tile is selected |
