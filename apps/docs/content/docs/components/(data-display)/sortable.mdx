## Usage
Use `Sortable` to create a reorderable list where users can drag items into a new position using a handle.

```tsx
import { Sortable } from "@moto-ui/react"

<Sortable gap="12">
	<Sortable.Item index={1} id="1">
		<Sortable.ItemHandle>
			...
		</Sortable.ItemHandle>
	</Sortable.Item>
	<Sortable.Item index={2} id="2">
		<Sortable.ItemHandle>
			...
		</Sortable.ItemHandle>
	</Sortable.Item>
</Sortable>
```

## Data Attributes

**Root**

| Attribute | Description |
|-----------|-------------|
| `[data-scope="sortable"]` | The component scope. |
| `[data-part="root"]` | The component part. |

**Item**

| Attribute | Description |
|-----------|-------------|
| `[data-scope="sortable"]` | The component scope. |
| `[data-part="item"]` | The component part. |
| `[data-dragging]` | Present when the item is being dragged. |
| `[data-dropping]` | Present when an item is being dropped on this target. |
| `[data-state="dragging" | "dropping" | "idle"]` | Current drag state of the item. |

**ItemHandle**

| Attribute | Description |
|-----------|-------------|
| `[data-scope="sortable"]` | The component scope. |
| `[data-part="item-handle"]` | The component part. |
| `[data-dragging]` | Present when the item is being dragged. |
| `[data-dropping]` | Present when an item is being dropped on this target. |
| `[data-state="dragging" | "dropping" | "idle"]` | Current drag state of the item. |

## Accessibility
- Each sortable item is rendered as a `listitem` within a `list` region.
- The drag handle provides a visible affordance for reordering.
- Items receive `data-state` attributes for styling drag and drop states.
- Use `aria-label` on icon handles for screen reader support.
