### Usage
Use QrCode to render a scannable QR code from any string (for example, a URL or identifier). Provide the data you want to encode, and the component will generate the QR image.

```tsx 
import { QrCode } from "@moto-ui/react"

<QrCode.Root value="https://moto-ui.com">
  <QrCode.Frame>
    <QrCode.Pattern />
  </QrCode.Frame>
</QrCode.Root>
```

### Props

**Root**

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| value | `string` | - | The controlled value to encode. |
| defaultValue | `string` | - | The initial value to encode when rendered. |
| encoding | `QrCodeGenerateOptions` | - | The qr code encoding options. |
| onValueChange | `(details: ValueChangeDetails) => void` | - | Callback fired when the value changes. |
| pixelSize | `number` | - | The pixel size of the qr code. |
| id | `string` | - | The unique identifier of the machine. |
| ids | `Partial<{ root: string; frame: string }>` | - | The element ids. |
| asChild | `boolean` | - | Use the provided child element as the default rendered element. |

**RootProvider**

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| value | `UseQrCodeReturn` | - | The qr code instance (Required) |
| asChild | `boolean` | - | Use the provided child element as the default rendered element |

**Frame**

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| asChild | `boolean` | - | Use the provided child element as the default rendered element |

**Pattern**

| Prop | Type | Default | Description |
| --- | --- | --- | --- |

**Overlay**

| Prop | Type | Default | Description |
| --- | --- | --- | --- |

**DownloadTrigger**

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
