## Usage
Use `Avatar` to show a user’s profile picture with a graceful fallback when no image is available or it fails to load.
```tsx
import { Avatar } from "@moto-ui/react"

<Avatar>
  <Avatar.Image src="..." alt="..." />
  <Avatar.Fallback>JD</Avatar.Fallback>
</Avatar>
```

## Props

**Root**

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| colorPalette | `ColorPalette` | `"accent"` | The color palette of the component. |
| variant | `"primary" \| "secondary" \| "tertiary" \| "surface"` | `"primary"` | The variant of the component. |
| size | `"2xs" \| "xs" \| "sm" \| "md" \| "lg" \| "xl" \| "2xl"` | `"md"` | The size of the component. |
| asChild | `boolean` | `false` | Use the provided child element as the default rendered element. |
| ids | `Partial<{ root: string; image: string; fallback: string }>` | - | The ids of the elements in the avatar. Useful for composition. |
| onStatusChange | `(details: StatusChangeDetails) => void` | - | Function called when the image loading status changes. |

**RootProvider**

| Prop | Type | Default | Description |
|------|------|----------|-------------|
| value | `UseAvatarReturn` | - | The context value returned by `useAvatar`. |
| asChild | `boolean` | `false` | Use the provided child element as the default rendered element. |

**Image**

| Prop | Type | Default | Description |
|------|------|----------|-------------|
| asChild | `boolean` | `false` | Use the provided child element as the default rendered element. |

**Fallback**

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| asChild | `boolean` | `false` | Use the provided child element as the default rendered element. |

**Context**

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| children | `(context: UseAvatarContext) => React.ReactNode` | - | Render prop that provides access to the avatar context. |
