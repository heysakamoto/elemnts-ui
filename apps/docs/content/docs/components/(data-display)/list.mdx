## Usage
Present a collection of items in a structured vertical layout. It supports both unordered and ordered lists, custom indicators, and nested hierarchies.

```tsx
import { List } from "@elemnts-ui/react"

export function Demo() {
  return (
    <List.Root>
      <List.Item>Introduction to Elemnts UI</List.Item>
      <List.Item>Installation and Setup</List.Item>
      <List.Item>Component Overview</List.Item>
    </List.Root>
  )
}
```

## Ordered List
Use the **as** prop to render an ordered list. Apply custom styles to adjust the list numbering as needed.
