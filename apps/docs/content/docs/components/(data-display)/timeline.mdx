## Usage

The `Timeline` component is used to display a sequence of events, steps, or milestones in chronological order. It consists of items with separators containing an indicator dot and an optional connector line.

```tsx
import { Timeline } from "@elemnts-ui/react"

<Timeline>
	<Timeline.Item>
		<Timeline.Separator>
			<Timeline.Indicator />
			<Timeline.Connector />
		</Timeline.Separator>
		<Timeline.Content>
			<p>Event content</p>
		</Timeline.Content>
	</Timeline.Item>
</Timeline>
```
