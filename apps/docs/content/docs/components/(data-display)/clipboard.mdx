## Usage
Use the Clipboard to let users copy text (e.g., a code snippet or token) to their clipboard.
```tsx
import { Clipboard } from "@moto-ui/react"

<Clipboard value="Hello, World!">
  <Clipboard.Trigger>
    <Clipboard.Indicator />
  </Clipboard.Trigger>
  <Clipboard.Input />
</Clipboard>
```

## Props

**Root**

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| value | `string` | - | The controlled value of the clipboard |
| defaultValue | `string` | - | The initial value to be copied to the clipboard when rendered. |
| timeout | `number` | `3000` | The timeout for the copy operation |
| onStatusChange | `(details: CopyStatusDetails) => void` | - | The function to be called when the value is copied to the clipboard |
| onValueChange | `(details: ValueChangeDetails) => void` | - | The function to be called when the value changes |
| id | `string` | - | The unique identifier of the machine. |
| ids | `Partial<{ root: string; input: string; label: string }>` | - | The ids of the elements in the clipboard. Useful for composition. |
| asChild | `boolean` | - | Use the provided child element as the default rendered element |
