## Usage

Use Badge to attach a small indicator to another element (for notification counts, status dots, or short labels). Wrap the element you want to annotate, then render another Badge inside to act as the indicator, as shown below.

```tsx
import { Badge } from "@moto-ui/react";

<Badge>
  <Avatar />
  <Badge.Indicator>5</Badge.Indicator>
</Badge>;
```

## API Reference

### BadgeRoot
The root component.

| Prop         | Type  | Default       |
| ------------ | ----- | ------------- |
| variant      | `primary` \| `secondary` | `"primary"` | 
| size         | `xs` \| `sm` \| `md` \| `lg` \| `xl` | `"md"`|  
| placement    | `top-right` \| `top-left` \| `bottom-right` \| `bottom-left` | `"top-right"` | 

### BadgeIndicator
Displays counters, labels, or icons.

| Prop    | Type                | Default |
| ------- | ------------------- | ------- |
| as      | `React.ElementType` | -       |
| asChild | `boolean`           | -       |
