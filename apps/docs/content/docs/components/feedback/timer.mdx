## Overview

The Timer component provides a robust way to track time, supporting both countdowns and elapsed timers. It is highly configurable, allowing for custom display formats and control triggers.

## API Reference

### Props

**ActionTrigger**

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `action` | `TimerAction` | - | The action to perform (`start`, `pause`, `reset`). |
| `asChild` | `boolean` | - | Whether to merge props with child. |

**Area**

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `asChild` | `boolean` | - | Whether to merge props with child. |

**Control**

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `asChild` | `boolean` | - | Whether to merge props with child. |

**Item**

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `type` | `keyof Time<number>` | - | The unit type (e.g., `days`, `hours`, `minutes`, `seconds`). |
| `asChild` | `boolean` | - | Whether to merge props with child. |

**Root**

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `autoStart` | `boolean` | - | Whether the timer should start automatically. |
| `countdown` | `boolean` | - | Whether to count down. |
| `ids` | `Partial<{ root: string; area: string }>` | - | Custom IDs for parts. |
| `interval` | `number` | `1000` | Update interval in milliseconds. |
| `onComplete` | `() => void` | - | Called when timer completes. |
| `onTick` | `(details: TickDetails) => void` | - | Called on each tick. |
| `startMs` | `number` | - | Initial duration in milliseconds. |
| `targetMs` | `number` | - | Minimum count in milliseconds. |
| `asChild` | `boolean` | - | Whether to merge props with child. |

**RootProvider**

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `value` | `UseTimerReturn` | - | The timer instance. |
| `asChild` | `boolean` | - | Whether to merge props with child. |

**Separator**

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
