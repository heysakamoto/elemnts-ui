Moto UI components are designed with flexibility in mind, offering two primary ways to compose and change their rendered output: the `as` prop and the `asChild` prop. Both are powered by [Ark UI](https://ark-ui.com/).

## The as Prop

The `as` prop allows you to change the underlying HTML element that a component renders while retaining all its styles and behavior.

```tsx
import { Text } from "@moto-ui/react";

<Text as="h1">This renders as an H1 tag</Text>
<Text as="span">This renders as a span</Text>
```

## The asChild Prop

The `asChild` prop is the preferred way to compose a Moto UI component with another custom component or a framework-specific link (like TanStack Router or Next.js `Link`).

When `asChild` is set to `true`, the component will not render its own DOM element. Instead, it will pass its props and behavior to its **immediate** child.

```tsx
import { Button } from "@moto-ui/react";
import { Link } from "@tanstack/react-router";

<Button asChild>
  <Link to="/about">About Us</Link>
</Button>
```

### Important Rules for asChild

1.  **Single Child Only**: You must pass exactly one child element.
2.  **Prop Merging**: Props from the parent (Moto UI component) and the child are merged. If both have the same prop (like `onClick`), both functions will be executed.
3.  **Ref Forwarding**: The child component must support ref forwarding to work correctly with Ark UI's logic.

## Creating Custom Components

Moto UI exports `factory` and `styled` to help you build your own polymorphic, styled components.

### Using factory (Ark UI)

The `factory` (aliased from `ark`) provides a way to create HTML elements that support the `asChild` prop natively.

```tsx
import { factory } from "@moto-ui/react";

const MyComponent = factory.div;

<MyComponent asChild>
  <button>Click me</button>
</MyComponent>
```

### Using styled (Panda CSS)

The `styled` function combines an element (or a factory element) with a Panda CSS recipe or styles.

```tsx
import { styled, factory } from "@moto-ui/react";
import { myRecipe } from "../styled-system/recipes";

const MyStyledComponent = styled(factory.div, myRecipe);
```

### Prop Forwarding

By default, `styled` filters out style-related props so they don't leak to the DOM. You can customize this behavior using `shouldForwardProp`.

```tsx
import { styled } from "@moto-ui/react";

const CustomBox = styled("div", {}, {
  shouldForwardProp: (prop) => !prop.startsWith("$"),
});
```

## Best Practices

- **Use `as`** for simple HTML element swaps (e.g., changing a `p` to a `span`).
- **Use `asChild`** when you need to wrap a component that has its own internal logic or needs to be a specific component type (e.g., a Router `Link`).
- **Accessibility**: When changing elements (like using `as="button"` on a `div`), ensure you are also providing the necessary ARIA roles and keyboard interactions if the component doesn't already handle them.
