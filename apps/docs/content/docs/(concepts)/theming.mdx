Moto UI is built on a highly extensible architecture powered by [Panda CSS](https://panda-css.com). The entire theme—including colors, spacing, typography, and component recipes—can be customized or extended to fit your brand.

## The Base Preset

To get started, you must include the Moto UI base preset in your `panda.config.ts`. This preset contains all the core tokens, semantic variables, and component recipes.

```ts
import { basePreset } from "@moto-ui/preset-base";
import { defineConfig } from "@pandacss/dev";

export default defineConfig({
  preflight: true,
  presets: [basePreset],
  include: ["./src/**/*.{js,jsx,ts,tsx}"],
  outdir: "styled-system",
  jsxFramework: "react",
});
```

## Extending the Theme

You can extend Moto UI by adding your own design tokens or overriding existing ones within the `theme.extend` section of your configuration.

### Design Tokens

Tokens are the atomic values of your design system (e.g., specific colors, font sizes).

```ts
export default defineConfig({
  theme: {
    extend: {
      tokens: {
        colors: {
          brand: {
            primary: { value: "oklch(60% 0.15 250)" },
            secondary: { value: "oklch(70% 0.1 250)" },
          },
        },
        fonts: {
          heading: { value: "Geist, sans-serif" },
        },
      },
    },
  },
});
```

### Semantic Tokens

Semantic tokens map primitive tokens to specific contexts (e.g., `danger`, `success`, `bg.primary`). They are theme-aware, meaning they can have different values for light and dark modes.

```ts
export default defineConfig({
  theme: {
    extend: {
      semanticTokens: {
        colors: {
          danger: {
            value: {
              base: "{colors.red.70}",
              _dark: "{colors.red.60}",
            },
          },
          brand: {
            value: "{colors.brand.primary}",
          },
        },
      },
    },
  },
});
```

### Text Styles

Text styles allow you to group multiple typography properties into a single reusable style.

```ts
import { defineTextStyles } from '@pandacss/dev'

export const textStyles = defineTextStyles({
  hero: {
    value: {
      fontFamily: "{fonts.heading}",
      fontWeight: "bold",
      fontSize: "4xl",
      lineHeight: "tight",
    },
  },
})

export default defineConfig({
  theme: {
    extend: { textStyles },
  },
});
```

## Component Customization

Moto UI components are styled using **Recipes** and **Slot Recipes**. You can override these in your configuration to change the default appearance of any component.

### Overriding Recipes

To change the styling of a component like `Button`, you can redefine its recipe:

```ts
export default defineConfig({
  theme: {
    extend: {
      recipes: {
        button: {
          base: {
            fontWeight: "bold",
            borderRadius: "full",
          },
        },
      },
    },
  },
});
```

## Best Practices

- **Use `extend`**: Always place your customizations inside `theme.extend` to ensure you don't accidentally wipe out the entire Moto UI base theme.
- **Reference Tokens**: Use the `{category.name}` syntax to reference other tokens within your configuration.
- **Theme Awareness**: Use semantic tokens for any colors that should change between light and dark modes.
- **Consistency**: Stick to the provided duration and easing tokens to maintain the "Moto" feel, even when changing colors or typography.
