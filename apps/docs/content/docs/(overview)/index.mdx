## About Moto UI

Moto UI is a **fast, accessible, and flexible** component library for building modern web applications. It combines the power of **Ark UI** for accessible, unstyled component logic with **Panda CSS** for type-safe, build-time styling—giving you full control without sacrificing performance.

## Core Technologies

Moto UI is built on a modern, optimized stack designed for speed, reliability, and developer happiness.

### Ark UI
We use [Ark UI](https://ark-ui.com/) for foundational component logic. It provides unstyled, accessible, and customizable components that follow WAI-ARIA standards—so accessibility is built-in from the ground up.

### Panda CSS
Our styling is powered by [Panda CSS](https://panda-css.com/), a modern CSS-in-JS engine. Styles are generated at build time, resulting in **zero runtime overhead**, lightning-fast performance, and type-safe styling.

## Core Principles

### Built for Accessibility
Moto UI components are designed with accessibility as a priority. By leveraging Ark UI’s headless logic, we ensure every component meets WAI-ARIA standards—making your apps usable for everyone, including people using assistive technologies.

### Type-Safe by Design
Written entirely in TypeScript, Moto UI provides **autocompletion, strict type checking, and compile-time error detection**—helping you catch issues early and build with confidence.

### Flexible Composition
We use the **Compound Component Pattern**, giving you the freedom to compose complex UI elements while keeping your code clean, declarative, and maintainable.

### Customizable & Performant
With Panda CSS, Moto UI offers a powerful system of **recipes and tokens** for easy customization. Styles are extracted at build time, so your app stays fast and responsive—no runtime bloat.
