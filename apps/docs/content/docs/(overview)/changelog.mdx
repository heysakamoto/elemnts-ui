## [0.0.9] - 2026-06-14
### Added
- Add `SeparatorGroup` component for grouping separators with optional captions
- Add `FocusTrap` utility component for trapping keyboard focus within a DOM subtree
- Add `VisuallyHidden` utility component for screen-reader-only accessible content
- Add `status` variant (`default`, `accent`, `success`, `warning`, `destructive`) to the Alert component
- Add `elevated` variant to the Alert component
- Add `accent`, `warning`, `success`, and `destructive` semantic color token groups
- Add `SeparatorGroup`, `FocusTrap`, and `VisuallyHidden` components from `@moto-ui/react`

### Fixed
- Refactor Alert from a Collapsible-based interactive component to a simplified static design; replace `Alert.Media` with `Alert.Indicator` and `Alert.Content`; remove `Alert.Trigger`, `Alert.RootProvider`, and `Alert.Context`
- Refactor Surface to use the elevated recipe as its base instead of inline elevation data attributes
- Rename `BaseElevated` to `ElevatedBase` and make `delta` prop optional (defaults to `0`)
- Update icon and foreground secondary semantic token values for improved contrast
- Fix success and warning status color values in dark mode for better visibility
- Fix group and button-group overlapping border issue by removing negative margin overlap between adjacent items
- Improve checkbox checked-state animation by removing extraneous border transition and adding `inset: 0` to the pseudo-element
- Remove focus outline from Switch and Segment Group trigger elements on `:focus-visible`
- Change `Alert.Title`, `Surface.Title`, and `EmptyState.Title` to render as `strong` instead of heading elements

## [0.0.8] - 2026-06-12
### Added
- Add `Table` component with support for variants, sizes, pinned headers, alternating rows, interactive rows, column dividers, captions, and footers
- Add `EmptyState` component with customizable indicator, title, description, and action control
- Add invalid state styles (destructive outline) to `Input`, `Textarea`, and `InputGroup` components
### Fixed
- Remove global invalid state styles
- Refactor font-size tokens in `Input`, `Textarea`, and `InputGroup` from CSS variables to direct design token references
- Improve `InputGroup` layout by using flex grow/shrink properties for inputs and textareas
- Add `colors` package documentation to the project readme

## [0.0.4] - 2026-06-01

### Added
- **Show**: A utility component for conditionally rendering content based on a truthy condition.
```tsx
import { Show } from "@moto-ui/react";

export function App() {
  return (
    <Show when={condition}>
      <ComponentToRender />
    </Show>
  )
}
```
- **List**: A compound component for rendering ordered and unordered lists with customizable item indicators.

  ```tsx
  import { List } from "@moto-ui/react";

  export function App() {
    return (
      <List.Root>
        <List.Item>
          <List.Indicator />
          Semantic color system
        </List.Item>
        <List.Item>
          <List.Indicator />
          Build-time CSS-in-JS
        </List.Item>
      </List.Root>
    );
  }
  ```

- **Code**: An inline code element with recipe-based styling, ideal for rendering code snippets within text.

  ```tsx
  import { Code } from "@moto-ui/react";

  export function App() {
    return (
      <p>
        Use the <Code>Code</Code> component for inline code.
      </p>
    );
  }
  ```

- **Prose**: A styled container for rendering rich text and markdown content with typographic defaults.

  ```tsx
  import { Prose } from "@moto-ui/react";

  export function App() {
    return (
      <Prose>
        <h1>Article Title</h1>
        <p>Beautifully styled typography out of the box.</p>
      </Prose>
    );
  }
  ```

- **Blockquote**: A compound component for displaying quoted content with citation and caption support.

  ```tsx
  import { Blockquote } from "@moto-ui/react";

  export function App() {
    return (
      <Blockquote.Root>
        <Blockquote.Indicator />
        <Blockquote.Content>
          The best way to predict the future is to create it.
        </Blockquote.Content>
        <Blockquote.Cite>Peter Drucker</Blockquote.Cite>
        <Blockquote.Caption>
          Management consultant and educator
        </Blockquote.Caption>
      </Blockquote.Root>
    );
  }
  ```

- **Breadcrumb**: A compound navigation component that provides a trail of links for users to track their location.

  ```tsx
  import { Breadcrumb } from "@moto-ui/react";

  export function App() {
    return (
      <Breadcrumb.Root>
        <Breadcrumb.List>
          <Breadcrumb.Item>
            <Breadcrumb.Link href="/">Home</Breadcrumb.Link>
          </Breadcrumb.Item>
          <Breadcrumb.Separator />
          <Breadcrumb.Item>
            <Breadcrumb.Link href="/docs">Docs</Breadcrumb.Link>
          </Breadcrumb.Item>
          <Breadcrumb.Separator />
          <Breadcrumb.Item>
            <Breadcrumb.CurrentLink>Installation</Breadcrumb.CurrentLink>
          </Breadcrumb.Item>
        </Breadcrumb.List>
      </Breadcrumb.Root>
    );
  }
  ```
