## 0.0.10

<Timeline>
  <TimelineItem index={1} title="What's New">
    - **ColorScheme**: A new component with subcomponents to manage light, dark, and system color scheme preferences. Includes optional `localStorage` persistence for user preferences.
    - **SkipNav**: Helps keyboard and screen reader users skip repetitive navigation, improving accessibility.
    - **Theme**: Wrap content in a specific color scheme (`light` or `dark`) using the `appearance` prop.
    - **useMediaQuery**: A new hook to track CSS media query states in React components.
    - **useScrollShadow**: Publicly exported the `useScrollShadow` hook from the ScrollShadow component for easier access.
  </TimelineItem>
  <TimelineItem index={2} title="Improvements">
    1. Renamed the `tone` variant to `surface` in the `item` and `tag` recipes (affects components like Item, Tag, Tile, and more).
    2. Updated semantic color tokens to use `_light`/`_dark` conditions instead of `base` for better dark mode handling.
    3. Refactored semantic shadow tokens to use `light`/`dark` conditions instead of `base`.
    4. Changed breakpoints from pixel values to `rem` values for better accessibility.
    5. Updated paragraph global styles to use the `fg.secondary` color for improved readability.
  </TimelineItem>
</Timeline>

## 0.0.9

<Timeline>
  <TimelineItem index={1} title="What's New">
    - **SeparatorGroup**: Group separators with optional captions for better organization.
    - **FocusTrap**: A utility component to trap keyboard focus within a DOM subtree, improving accessibility.
    - **VisuallyHidden**: A utility component for screen-reader-only accessible content.
    - **Alert Component Updates**:
      - Added new `status` variants (`default`, `accent`, `success`, `warning`, `destructive`).
      - Added an `elevated` variant for enhanced visual hierarchy.
    - **Semantic Color Tokens**: Added new `accent`, `warning`, `success`, and `destructive` semantic color token groups.
  </TimelineItem>
  <TimelineItem index={2} title="Improvements">
    1. Refactored the **Alert** component from a Collapsible-based interactive design to a simplified static design. Replaced `Alert.Media` with `Alert.Indicator` and `Alert.Content`. Removed `Alert.Trigger`, `Alert.RootProvider`, and `Alert.Context`.
    2. Refactored the **Surface** component to use the elevated recipe as its base instead of inline elevation data attributes.
    3. Renamed `BaseElevated` to `ElevatedBase` and made the `delta` prop optional (defaults to `0`).
    4. Updated icon and foreground secondary semantic token values for improved contrast.
    5. Fixed success and warning status color values in dark mode for better visibility.
    6. Resolved group and button-group overlapping border issues by removing negative margin overlaps between adjacent items.
    7. Improved checkbox checked-state animation by removing extraneous border transitions and adding `inset: 0` to the pseudo-element.
    8. Removed focus outlines from Switch and Segment Group trigger elements on `:focus-visible`.
    9. Changed `Alert.Title`, `Surface.Title`, and `EmptyState.Title` to render as `strong` instead of heading elements.
  </TimelineItem>
</Timeline>

## 0.0.4

<Timeline>
  <TimelineItem index={1} title="What's New">
    **Show**: A utility component for conditionally rendering content based on a truthy condition.

    ```tsx
    import { Show } from "@moto-ui/react";

    export function App() {
      return (
        <Show when={condition}>
          <ComponentToRender />
        </Show>
      )
    }
    ```
    ---

    **List**: A compound component for rendering ordered and unordered lists with customizable item indicators.

    ```tsx
    import { List } from "@moto-ui/react";

    export function App() {
      return (
        <List.Root>
          <List.Item>
            <List.Indicator />
            Semantic color system
          </List.Item>
          <List.Item>
            <List.Indicator />
            Build-time CSS-in-JS
          </List.Item>
        </List.Root>
      );
    }
    ```
    ---

    **Code**: An inline code element with recipe-based styling, ideal for rendering code snippets within text.

    ```tsx
    import { Code } from "@moto-ui/react";

    export function App() {
      return (
        <p>
          Use the <Code>Code</Code> component for inline code.
        </p>
      );
    }
    ```
    ---

    **Prose**: A styled container for rendering rich text and markdown content with typographic defaults.

    ```tsx
    import { Prose } from "@moto-ui/react";

    export function App() {
      return (
        <Prose>
          <h1>Article Title</h1>
          <p>Beautifully styled typography out of the box.</p>
        </Prose>
      );
    }
    ```
    ---

    **Blockquote**: A compound component for displaying quoted content with citation and caption support.

    ```tsx
    import { Blockquote } from "@moto-ui/react";

    export function App() {
      return (
        <Blockquote.Root>
          <Blockquote.Indicator />
          <Blockquote.Content>
            The best way to predict the future is to create it.
          </Blockquote.Content>
          <Blockquote.Cite>Peter Drucker</Blockquote.Cite>
          <Blockquote.Caption>
            Management consultant and educator
          </Blockquote.Caption>
        </Blockquote.Root>
      );
    }
    ```
    ---
    
    **Breadcrumb**: A compound navigation component that provides a trail of links for users to track their location.

    ```tsx
    import { Breadcrumb } from "@moto-ui/react";

    export function App() {
      return (
        <Breadcrumb.Root>
          <Breadcrumb.List>
            <Breadcrumb.Item>
              <Breadcrumb.Link href="/">Home</Breadcrumb.Link>
            </Breadcrumb.Item>
            <Breadcrumb.Separator />
            <Breadcrumb.Item>
              <Breadcrumb.Link href="/docs">Docs</Breadcrumb.Link>
            </Breadcrumb.Item>
            <Breadcrumb.Separator />
            <Breadcrumb.Item>
              <Breadcrumb.CurrentLink>Installation</Breadcrumb.CurrentLink>
            </Breadcrumb.Item>
          </Breadcrumb.List>
        </Breadcrumb.Root>
      );
    }
    ```
  </TimelineItem>
</Timeline>
