## Setup Guide
Follow these steps to set up Moto UI and its styling engine, Panda CSS.
<Timeline>
  <TimelineItem index={1} title="Prerequisites">
    Before you begin, make sure your Panda project is properly configured. If you haven't set it up yet, follow the [Panda CSS Getting Started Guide](https://panda-css.com/docs/overview/getting-started) to get started, then return here once complete.
  </TimelineItem>
  <TimelineItem index={2} title="Install dependencies">
    Moto UI is built on Ark UI as its headless foundation and uses Panda CSS for styling.
    ```npm title="Terminal"
    npm install @moto-ui/core @moto-ui/react
    npm install -D @pandacss/dev
    ```
  </TimelineItem>
  <TimelineItem index={3} title="Initialize PandaCSS">
    Initialize Panda CSS in your project if you haven't already. Run the following command in your terminal:
    ```npm
    npm run panda init --postcss
    ```
    Then, update your **panda.config.ts** to include the Elemnts base preset.    
    ```ts title="panda.config.ts"
    import { basePreset } from "@moto-ui/core/presets";
    import { defineConfig } from "@pandacss/dev";
    export default defineConfig({          
      presets: [basePreset],
      include: [
        "src/**/*.{js,jsx,ts,tsx}",
        "node_modules/@moto-ui/react/dist/panda.buildinfo.json",
      ],
    });
    ```
  </TimelineItem>
  <TimelineItem index={4} title="Add components">
    You can now start adding components to your project.
    ```tsx
    import { Button } from "@moto-ui/react";
    export function Welcome() {
      return (
        <Button variant="primary">Get Started</Button>
      );
    }
    ```
    And you're good to go! Happy building!
  </TimelineItem>
</Timeline>
